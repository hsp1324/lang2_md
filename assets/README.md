# Development assets

This directory contains source and reference assets used to build or verify the
project. Files embedded directly in documentation remain under `docs/assets/`,
while runtime assets remain under `editor/static/`.

- `class-sprites/source/`: tracked sprite masters and reproducible build inputs
- `class-sprites/reference/`: comparison sheets and design references

Generated experiments and archived candidates are excluded by `.gitignore` and
should not be committed here.
