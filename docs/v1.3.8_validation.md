# v1.3.8 검증 기록

> 범위: **로렌 색상 교정만 대상**. 사용자의 요청에 따라 기존 시나리오 전체
> 재진행·룬스톤·전투 검증은 이번 빌드에서 다시 수행하지 않았습니다.

v1.3.8은 v1.3.7의 게임 로직을 유지하고, 최신 디자인 Normal·Hard의 로렌
맵 스프라이트 팔레트 두 칸만 빨강 명암으로 바꾼 빌드입니다.

## 시나리오 2 시작 확인

격리된 Xvfb 가상 화면에서 Normal v1.3.8의 실제 시나리오 2 시작 준비 화면을
열었습니다. 고정 배치 레코드 10개가 모두 일치했고, 로렌 레코드(첫 번째)는
다음 값으로 확인했습니다.

| 필드 | 값 |
| --- | --- |
| 클래스 | `0x9B` (로렌 하이로드) |
| 이름 ID | `0x26` |
| 진영 | `0x03` |
| 레벨 | `7` |
| 좌표 | `(19, 19)` |
| 용병 | `100, 100, 106, 106` |

런타임의 해당 맵 스프라이트 팔레트에서 로렌 갑옷에 쓰이는 색상은 밝은 빨강
`B = (219, 0, 0)`, 짙은 빨강 `C = (109, 0, 0)`으로 확인했습니다. 이전 연보라
색상 `E = (73, 73, 109)`은 갑옷 램프에 사용하지 않습니다. 검과 방패의 보호
색상은 그대로 남습니다.

## 재현 및 패키지 확인

검증한 일본판 원본 SHA-256은
`a6e10e82b1e8fd32d8e4ae2ce76ab689cd789d93f854aa1788abc1e9795ddb3b`입니다.
다음 명령은 세 BPS가 현재 ROM 결과와 바이트 단위로 일치하고, 원본에서
왕복 적용되는지 확인합니다.

```bash
python3 tools/build_v138_release_patches.py --check
python3 -m unittest \
  tests.test_bald_map_sprite \
  tests.test_editor_model \
  tests.test_v120_release_patcher
```

v1.3.7에서 이미 배포된 로직을 재검증했다는 뜻이 아닙니다.
