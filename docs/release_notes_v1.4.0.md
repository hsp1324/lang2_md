# v1.4.0 릴리스 노트

## 시나리오 1 프롤로그 줄바꿈

`그러던 어` / `느 날`로 단어가 갈라지던 일본판 고정 줄바꿈 위치를 한 칸
앞으로 옮겼습니다. 이제 앞줄은 `평온하던`으로 끝나고 다음 줄은
`어느 날 헤인은`으로 자연스럽게 시작합니다. 동적 주인공 이름의 삽입 위치와
나머지 설명 레코드 배치는 바꾸지 않았습니다.

## 세 판의 구성 분리

- Original은 키스·레스터·제시카의 초기 로스터와 전직 진행을 일본판 원본으로
  복원했습니다. 세 인물은 원작처럼 2단계 클래스와 원래 레벨로 등장하며,
  최신 New 디자인과 사용자 합류 선택 로직을 적용하지 않습니다.
- Normal은 최신 New 클래스 디자인을 유지합니다. 키스·레스터·제시카는 합류
  때 2단계 클래스를 직접 선택할 수 있도록 1단계 LV10으로 등장하고, 선택 뒤
  지급되는 경험치량은 원작과 같습니다.
- Hard는 Normal의 구성과 승인된 하드 밸런스를 유지하면서 모든 일반·비밀
  상점에 룬스톤과 경험치 2배 효과의 메사이어소드를 추가했습니다.

## 크레딧

마지막 엔딩 크레딧의 한국어 번역자 표기를 `홍선표(hsp1324)`로 변경했습니다.
타이틀 화면의 기존 짧은 한글화 표기는 그대로입니다.

## 호환성

게임 내 SRAM 저장 형식은 계속 `lang2-ko-sram-v1`입니다. 다만 이미 저장에
생성된 지휘관의 클래스와 레벨은 ROM의 초기 로스터 변경이 소급되지 않으므로,
Original의 원작 합류 상태는 새 게임에서 확인해야 합니다. 버전 사이에는 상태
저장 대신 게임 안에서 저장한 `.srm`을 사용하세요.

세부 해시와 데이터 검증 결과는 [v1.4.0 검증 기록](v1.4.0_validation.md)을
참고하세요.
