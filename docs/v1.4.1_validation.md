# v1.4.1 검증 기록

## 용병 고용 이름

- 클래스 ID `0x6A`의 고용창 이름 레코드는 `엘프`의 두 글자를 모두 로컬
  글리프 인덱스로 참조합니다.
- `프`의 기존 고정 타일 `0x03F7` 대신 준비 화면 스크래치 슬롯 24의
  `0x07EB`를 사용합니다.
- 로얄가드의 `가`와 글래디에이터의 `디`, 엔젤의 `엔`은 서로 다른
  스크래치 슬롯을 사용합니다.
- 전체 준비·고용·전직 동시 표시 모델 69,449건에서 슬롯 충돌은 0건입니다.
- v1.4.0과 바이트 단위로 비교하면 각 판에서 바뀐 것은 버전 문자, MD 체크섬,
  `프`와 `가`의 준비 화면 슬롯 바이트뿐이며 게임 밸런스 데이터 변화는
  없습니다.
