# v1.4.2 검증 기록

## 시나리오 26 → X4 진입 판정

- 원작 판정 루틴 `0x017386`과 이벤트 게이트 `0x1B23AE`를 일본판 원본과
  바이트 단위로 대조했습니다.
- Normal·Hard에서만 두 즉시값을 변경했습니다.
  - `0x017391`: 검사할 본편 클리어 기록 수 `0x19` → `0x18`
  - `0x01739F`: X1 기록으로 이동할 거리 `0x01` → `0x02`
- Original은 위 두 바이트를 포함한 원작 진입 판정을 유지합니다.
- 이벤트 게이트와 수락 시 목적지인 내부 시나리오 `0x1F`(표시 X4)는
  변경하지 않았습니다.
- 시나리오 1–25, X1–X3, 생존·누적 퇴각 조건이 그대로 남는 것을 판정
  루틴과 자동 테스트로 확인했습니다.

- Normal: 버전 문자, MD 체크섬, 위 진입 판정 2바이트만 변경
