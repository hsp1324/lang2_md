# v1.3.9 릴리스 노트

## 제보 수정

- 전장 지휘관의 `명령` 하위 메뉴가 실제로 참조하는 글꼴 슬롯을 수정해 마지막
  명령을 `자동`에서 `수동`으로 바꿨습니다. 별도 `자동배치`는 그대로 유지합니다.
- 상점 목록·구매 팝업에서 긴 아이템 이름의 글꼴 타일이 덮어써져 `크라운`,
  `천사날개`, `그레이프니르` 등이 깨지던 문제를 수정했습니다. 철회한 후보가
  상점의 B400/B700/B800 그래픽을 글꼴로 덮어 단검 옆 문양과 AT/DF 앞 `니`를
  만들던 방식은 폐기하고, 안전한 A700 이름 영역을 상점에서 다시 읽습니다.
- 시나리오 1 서장을 `헤인의 소꿉친구 리아나` 및 `엘윈은 리아나를 구하기 위해
  검을 들었다`가 자연스럽게 이어지도록 교정했습니다.
- 시나리오 15의 이멜다 분기에서 실제 일본판 물리 이벤트 페이지와 영문 참조 번호를
  혼동해, 적 지휘관 격파 뒤 대사가 섞이거나 순서가 밀리던 문제를 수정했습니다.
- 레스터 아크메이지에서 숨은 `자베러`가 선택 목록에 없던 전직 경로를 추가했습니다.
- 마법 무효 결과에 쓰는 원래 `ミス` 글리프 두 칸을 한국어 이름 글꼴이 재사용해
  `프린`처럼 보이던 VRAM 충돌을 제거했습니다.

## 호환성

게임 내 SRAM 저장 형식은 계속 `lang2-ko-sram-v1`입니다. 새 ROM으로 이어서
플레이할 때는 게임 안에서 저장한 `.srm`을 사용하고, 다른 해시의 상태 저장
(`.state`, `.gst`)은 불러오지 않는 것을 권장합니다.

정확한 BPS·ROM 검증값과 가상 화면 확인 범위는
[v1.3.9 검증 기록](v1.3.9_validation.md)을 따릅니다.
철회한 구현의 원인과 클린 재검증 과정은
[v1.3.9 클린 재작업 감사 기록](v1.3.9_clean_rebuild_audit.md)에 남깁니다.
