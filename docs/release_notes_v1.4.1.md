# v1.4.1 릴리스 노트

## 용병 고용창 이름 수정

용병 고용창에서 `엘프`의 마지막 글자 `프`가 용병 아이콘 조각에 덮여
`엘ㅡ`처럼 보이던 문제를 수정했습니다. `프`는 원래 고정 글꼴 타일
`0x03F7`을 사용했지만, 이 타일은 같은 화면의 용병 아이콘 캐시가 사용합니다.

v1.4.1에서는 `프`를 준비·고용 화면 전용 안전 스크래치 타일 `0x07EB`로
동기 렌더링합니다.

`로얄가드` 상태에서 용병을 고용할 때 같은 동적 글꼴 슬롯의 `가`가
`글래디에이터`의 `디`를 덮어 `글래가에이터`로 보이던 문제도 수정했습니다.
`가`를 충돌 없는 별도 슬롯으로 옮겼습니다.

31개 시나리오, 모든 지휘관 클래스, 새 호크·크로코 계열과 로얄가드,
16종 용병의 여섯 고용 페이지 및 전직 화면을 합친 69,449개 동시 표시
문맥에서 26개 스크래치 슬롯의 문자 충돌이 없음을 검사했습니다.

## 호환성

게임 밸런스와 SRAM 형식은 v1.4.0과 같습니다. 버전 사이에는 상태 저장 대신
게임 안에서 저장한 `.srm`을 사용하세요.
