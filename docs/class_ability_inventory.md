# Class Ability Inventory

Generated from the Japanese REV00 ROM by `python3 tools/class_ability_inventory.py`.

## Runtime Contract

- Class records: `0x05EDDC`, stride `0x1C`, ability bytes `0x16`, `0x17`, `0x18`, `0x19`
- Ability requirements: `0x0829CC`
- Ability masks: `0x0829FA`
- Magic command mask: `0x00000001`
- Summon command mask: `0x00800000`
- Level-up scan: `0x014946..0x01498A`
- Magic list builder: `0x0211A2..0x02125A`
- Semantics: A stock level-up learns each current-class ability whose required level is not greater than the new level. Class change alone does not scan the new class.
