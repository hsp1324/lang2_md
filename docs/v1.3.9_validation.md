# v1.3.9 검증 기록

> 범위: v1.3.8 이후 사용자 제보 수정과 해당 화면의 재현·회귀 검수입니다.
> 모든 실제 화면 확인은 물리 데스크톱이 아닌 격리된 Xvfb 가상 화면 `:121`에서
> BlastEm 소프트웨어 렌더러와 Xlib 캡처로 수행했습니다.

## 실제 화면 확인

- 초기 후보는 전장과 무관한 자동 배치 글꼴만 바꿔 실제 `명령` 하위 메뉴가
  여전히 `자동`인 것을 재현했습니다. 실제 전장 글꼴 목록 `0x09706A`의
  24번 슬롯을 수정한 뒤, Normal 후보에서 `이동 / 공격 / 방어 / 수동`이
  표시되고 별도 준비 화면은 `자동배치`로 유지되는 것을 확인했습니다.
- 상점 ID 1~37을 실제로 한 행씩 이동하며 `크라운`, `천사날개`, `그레이프니르`를
  포함한 모든 이름·아이콘·설명과 오른쪽 상태 패널이 깨지지 않는 것을 확인했습니다.
- 시나리오 1 준비 화면의 상점 진입 전후 14개 대응 화면은 모두 픽셀 동일했고,
  단검 구입·판매 팝업과 준비 화면 복귀에도 커서 잔상이 없었습니다.
- 새 게임 시나리오 1의 실제 서장 스크롤에서 `헤인의 소꿉친구 리아나` 문장을
  확인했습니다. 동적 이름 치환 뒤의 마지막 문장은 빌드 회귀 검사에서
  `엘윈은 리아나를 구하기 위해 검을 들었다.`로 고정했습니다.
- 레스터를 아크메이지 상태로 놓은 진단에서 클래스 체인지 선택창의 `자베러`와,
  적용 뒤 상태창의 `레스터 / 자베러 / LV 1`을 확인했습니다.
- 시나리오 15는 원본 이벤트를 보존하고 적 지휘관 한 명만 엘윈 옆에서 실제
  일반 공격으로 격파했습니다. 격파 지휘관의 구조 요청, 이멜다의 답변,
  퇴각·증원·위협·임무 복귀, 헤인·레스터 반응과 다른 지휘관의
  `이렇게 된 이상 돌격이다!`까지 총 18개 대사가 순서대로 진행됐습니다.
  턴 카운터 1과 엘윈 행동 가능 상태로 다음 플레이어 턴에 정상 복귀했습니다.
- 마법 무효율을 255로 고정한 비배포 진단 ROM에서 실제 마법 적용·결과 경로를
  실행했습니다. `0x004A`, `0x03A9` 원래 결과 글리프 타일은 최종 ROM에서
  일본판과 바이트 단위로 같고, 한국어 `프`·`린`은 안전한 확장 타일
  `0x03F7`·`0x03F8`로 옮겼습니다. 매직애로우 MP가 `12→11`로 소비되고
  실제 MISS 오버레이가 `프린`으로 변하지 않는 것도 확인했습니다.
