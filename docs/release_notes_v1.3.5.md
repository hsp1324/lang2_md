# v1.3.5 릴리스 노트

## 수정 사항

- 키스가 룬스톤 사용 뒤 파이터에서 `매직나이트 / 드래곤나이트 / 비숍`을
  선택하게 되던 v1.3.2~v1.3.4 회귀를 수정했습니다. 정상 후보는
  `로드 / 호크나이트 / 힐러`입니다.
- 레스터의 파이터 룬스톤 경로도 `나이트 / 크로코나이트 / 샤먼`으로
  복구했습니다. 제시카 워록의 `힐러 / 소서러 / 로드` 경로도 함께
  대조했습니다.
- 합류 전용 호크로드·크로코로드 클래스 체인과 스프라이트 표를 ROM 확장
  영역으로 옮겼습니다. 새 게임의 세 인물은 레벨 10으로 등장해 아군 합류
  시점에 전직하고, v1.3.4에서 추가한 파이터 레벨 11 이상 구 세이브 자동
  복구도 유지됩니다.
- 시나리오 31의 왼쪽 데몬로드가 중복 이름 ID 때문에 전용 사망 이벤트를
  실행하지 못하던 원본 데이터 오류를 수정했습니다. 표시 이름과 클래스,
  밸런스 수치는 바뀌지 않습니다.

## 검증 범위

- 실제 데스크톱과 분리한 Xvfb 가상 화면에서 Original·Normal·Hard의
  시나리오 1~31 진입과 첫 턴을 93건 모두 확인했습니다.
- Normal·Hard 전 시나리오에서 실제 공격, 최종 적 HP 0, 결과 화면, 저장,
  분기와 엔딩을 새 후보 ROM으로 다시 실행했습니다.
- 시나리오 6 우물의 룬스톤은 Original과 Hard에서 실제 이동·획득했습니다.
- 시나리오 27은 에필로그와 `Fin`까지, 시나리오 31은 수정된 데몬로드의
  전용 사망 대사까지 확인했습니다.
- 정적 검사에서는 31개 시나리오의 고정 지휘관 340개를 비교하여 이름,
  클래스, 레벨, 진영, 좌표와 Normal/Hard 간 승인되지 않은 차이가 없음을
  확인했습니다.

게임 안에서 저장한 기존 `.srm` 형식은 그대로입니다. 새 ROM과 같은 기본
파일명으로 복사해 이어서 사용할 수 있으며, 이전 ROM의 상태 저장 파일
(`.state`, `.gst`)은 사용하지 않는 것이 안전합니다.

검증 방법과 장별 범위는 [v1.3.5 상세 검증 기록](v1.3.5_validation.md)에
정리되어 있습니다.
