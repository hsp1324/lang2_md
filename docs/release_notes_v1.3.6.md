# v1.3.6 릴리스 노트

## 수정 사항

- 키스의 호크로드가 공격할 때 시스터 그래픽을 사용하던 오류를
  수정했습니다. 호크로드의 맵 디자인, 능력치와 경험치 게이지도 더 이상
  드래곤나이트 데이터를 사용하지 않습니다.
- 같은 미완성 클래스 별칭 구조를 사용하던 레스터의 크로코로드도 함께
  수정했습니다. 크로코로드는 레스터의 탑승 맵·전투 그래픽과 올바른 성장
  데이터를 사용합니다.
- 룬스톤 첫 전직 행을 합류 시점의 선택지와 통일했습니다. 키스는
  `로드 / 호크로드 / 힐러`, 레스터는 `나이트 / 크로코로드 / 샤먼`,
  제시카는 기존과 같은 `힐러 / 소서러 / 로드`가 표시됩니다.

## 실제 실행 검증

- 데스크톱과 분리한 BlastEm 가상 화면에서 키스·레스터·제시카 각각의
  2·3·4·5단계, 총 12개 상태를 재현했습니다.
- 각 상태에서 실제 룬스톤 아이템 `0x1A`를 장착하고 턴 종료 레벨업 루틴을
  실행하여 아이템 소비, 2단계 선택창 표시, 선택 후 `LV1/EXP0` 초기화를
  확인했습니다.
- 키스와 레스터는 5단계에서 선택창의 두 번째 행으로 직접 이동하여
  호크로드(`0x2B`)와 크로코로드(`0x2C`) 적용까지 확인했습니다.
- 키스 호크로드의 실제 측면 전투 화면에서 시스터가 아닌 비행 탑승
  공격모션을 확인했습니다.

게임 안에서 저장한 기존 `.srm` 형식은 v1.3.5와 같으며 그대로 이어서
사용할 수 있습니다. 이전 ROM의 상태 저장 파일(`.state`, `.gst`)은 새 ROM에
사용하지 않는 것이 안전합니다.
