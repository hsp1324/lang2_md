# v1.3.7 릴리스 노트

> 상태: **공개 배포**. 직전 v1.3.7의 Original·Normal·Hard로 1장부터 비밀
> 시나리오를 포함한 마지막 27장과 Fin 화면까지 총 93개 장별 연속 저장 진행을
> 확인했습니다. 2026-08-12 재배포본은 같은 게임 로직을 유지하고 시나리오 1
> 대사 리소스만 추가 교정했으며, 아래에 새 정확 해시를 기록합니다.

## 수정 사항

- 시나리오 10 승리 결과에서 레스터가 아군으로 합류할 때 원작의 소속 판정에
  걸려 전직 선택이 생략되던 오류를 수정했습니다. 레스터가 `LV10`
  크로코나이트 상태로 합류하면 `나이트 / 크로코로드 / 샤먼` 선택창이 뜬 뒤
  결과 화면의 경험치와 레벨 상승이 이어집니다.
- 수정 루틴은 레스터(`지휘관 ID 9`)·시나리오 10·승리 결과 처리 호출에만
  추가 예외를 허용합니다. 키스와 제시카를 포함한 기존 소속 판정 및 다른
  시나리오의 결과 처리는 원작 흐름을 유지합니다.
- 합류 직후 경험치는 목표 레벨까지 반복 충전하지 않습니다. 키스 `0x00`,
  레스터 `0x90`, 제시카 `0x60`의 raw EXP를 한 번만 지급하며, 이 값은 원작
  2단계 클래스의 기존 레벨 바닥만 복원하고 원작의 잔여 EXP 바는 제외합니다.
  세 선택 분기와 Original/Normal/Hard에서 같은 값을 사용하므로 최종 LV/EXP는
  선택한 클래스 자체의 경험치 게이지가 결정하며, Hard 전용 추가 경험치는
  없습니다.
- 합류 경계에서 새 일회성 `0xA5` 마커가 설정된 경우에만 위 경험치를 지급합니다.
  v1.3.6 세이브에 남을 수 있는 옛 `0x5A` 값은 지급 없이 지우므로, 이후 실제
  룬스톤 사용은 합류 경험치를 다시 받지 않고 원작의 `LV1/EXP0` 재시작을
  유지합니다.
- v1.3.2/v1.3.3에서 만들어질 수 있었던 파이터 `LV10`, `LV11`, `LV12`
  레스터·키스 구 세이브의 복구 경로를 그대로 포함합니다. 각 경계값은 최종
  정확 버전에서 다시 실행 검증합니다.
- 일반 타이틀 화면의 `LOAD`로 구 SRAM을 불러오면 저장되는 현재 시나리오
  (`0xA49C`)와 저장되지 않는 시나리오 선택기 임시값(`0xA612`)이 달라질 수
  있었습니다. 일반 플레이와 cold/warm `LOAD`에서는 항상 저장된 현재
  시나리오를 사용하고, 스케줄러 스택의 바깥 콜백이 원작 결과 스캐너
  `0x00CEC4`임이 확인된 경우에만 다음 시나리오 임시값을 사용하도록
  수정했습니다. 따라서 warm `LOAD`에 0이 아닌 예전 선택기 값이 남아도
  합류 복구와 실제 룬스톤 선택창을 가리거나 잘못 열지 않습니다.
- 하드판에서 패배 조건에 직접 연결된 리아나·사제·주민·NPC 지휘관·제시카
  19명의 DF와 병사 D+를 같은 장의 적 공격 강화분만큼 보정했습니다. 리아나와
  제시카는 원작이 저장된 동료 성장값으로 능력치를 다시 계산하므로, 재계산이
  끝난 실제 값에 보정치를 더해 현재 클래스·레벨·AT는 그대로 유지합니다.
- 시나리오 14의 레온·엘윈 대사 뒤 빈 창과 엔딩의 스콧·아론·제시카 문장이
  단어 중간에서 다음 창으로 갈라지던 문제를 수정했습니다. 제보된 대사 175건을
  전수 대조해 원문 의미나 조사 오류가 명확한 48건도 반영했습니다.
- 2026-08-12 재배포에서 시나리오 1의 레아드·레온·제국군 지휘관 대사 6건을
  문맥에 맞게 추가 교정했습니다. 게임 로직과 저장 형식은 바뀌지 않습니다.

## 유지되는 클래스 수정과 검증 범위

- 룬스톤 사용 시 키스·레스터·제시카는 현재 단계가 2·3·4·5단계 중
  어디이든 각 인물의 올바른 2단계 선택창으로 돌아가야 합니다.
- 키스의 호크로드와 레스터의 크로코로드는 전용 맵 외형, 클래스 능력치,
  경험치 표시와 탑승 전투모션을 사용해야 합니다. 시스터·드래곤나이트 또는
  뱀파이어·서펜나이트 데이터로 되돌아가면 실패입니다.
- 위 항목은 합류·룬스톤·전투모션 전용 런타임 검사와, 체크섬까지 확정된
  아래 v1.3.7 바이너리의 1장부터 Fin까지 한 차례 전체 연속 진행으로
  확인했습니다.

### 시나리오 12 첫 턴 RNG 경계

- 콜드 LOAD 수정 전 후보에서 Original(`Pure`)과 Normal의 런타임 그룹은
  동일했고, WRAM 차이는 LCG 시드 경계의 1 VBlank로 확인됐습니다. 당시
  Original은 자연스러운 `HP0` 패배와 `HP1` 2턴 진입을 모두 재현했고,
  Normal과 Hard도 자연스러운 `HP0` 패배에 도달했습니다.
- 그러나 그 캡처는 현재 ROM 해시와 다르므로 최종 합격 근거에서 제외합니다.
  아래 새 정확 해시로 시나리오 1부터 다시 실행하며 시나리오 12도 다시
  통과해야 합니다.
- 따라서 검사 정책은 시나리오 12의 두 정상 종점인 2턴 진입 또는 자연스러운
  `HP0` 패배를 Original·Normal·Hard 각 프로필의 필수 해시 증거가 있을 때
  승인합니다. 이는 세 프로필 검사를 생략하는 예외가 아니라 RNG 경계 판정
  규칙입니다.
- 정확 ROM 합격 원칙에 따라 전체 최종 게이트는 아래 새 해시로 처음부터 다시
  실행합니다.

## 버전과 저장 호환성

- 원작 디자인판: 번역 `1.3.7`, 밸런스 버전 없음
- 최신 디자인 일반판: 번역 `1.3.7`, 밸런스 버전 없음
- 최신 디자인 하드판: 번역 `1.3.7`, 밸런스 `1.3.7`
- 보호 NPC 생존 보정으로 하드 밸런스도 1.3.7입니다. 두 버전이 같으므로
  파일명은 `Hard v1.3.7`로 표시하고, ROM 내부 메타데이터에는
  `T1.3.7 B1.3.7`을 기록합니다.
- 게임 내 `.srm` 저장 형식은 `lang2-ko-sram-v1`로 유지됩니다. 에뮬레이터
  상태 저장 파일(`.state`, `.gst`)은 다른 ROM 해시에 옮겨 쓰지 않는 것이
  안전합니다.
