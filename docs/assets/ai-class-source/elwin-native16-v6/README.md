# Elwin native16 v6

엘윈의 상위 중복 클래스 10개를 v5 원화에서 다시 편집한 AI 원화다.
각 클래스는 Codex 내장 이미지 편집을 별도로 실행해 만들었고, 원작
16×16 전신과 사용자가 저장한 머리 마스크를 동시에 비율 기준으로
사용했다.

v6의 우선순위는 다음과 같다.

1. 머리·머리카락·얼굴을 v5보다 약 35~40% 크게 그려 원작처럼 전신
   높이의 약 1/3 이상으로 읽히게 한다.
2. 검은 눈 픽셀과 그 왼쪽 흰자 픽셀을 포함한 얼굴 정체성은 원작
   참조를 따른다.
3. 갑옷·로브·말·장비는 작은 금장과 반복 하이라이트를 제거하고 큰
   색 덩어리와 재질별 하이라이트 하나만 남긴다.
4. 로드·하이로드·비숍·메이지·아크메이지·소드마스터·히어로는
   보행, 하이랜더·나이트마스터·실버나이트만 기마로 유지한다.

최종 16×16 변환은 `editor/ai_identity_masks.json`의 사용자 좌표에
원작 ROM 픽셀을 그대로 복원한다. 따라서 머리·얼굴·눈의 잠금 영역은
원작과 픽셀 단위로 일치하고, 잠금 영역 밖의 실루엣과 장비만 v6
디자인에서 가져온다.

`elwin-v6-ai-and-16x16.png`에서 AI 원화, 최종 16×16, 원작 ROM을
나란히 비교할 수 있다.
`comparisons/`에는 같은 세 이미지를 클래스별 PNG 한 장으로 분리해
두었다.
