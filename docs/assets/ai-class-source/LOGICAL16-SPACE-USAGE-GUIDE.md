# AI 클래스 스프라이트 16×16 공간 활용 가이드

이 문서는 새 캐릭터·클래스 AI 원화를 만들고 인게임 16×16 스프라이트로
변환할 때 좌우 공간, 얼굴 비율, 무기와 장비의 가독성을 유지하기 위한
공통 기준이다. 좌표는 왼쪽 위가 `(0, 0)`, 오른쪽 아래가 `(15, 15)`인
논리 16×16 기준이다.

## 1. 먼저 얼굴과 장비 영역을 배정한다

- 사용자가 저장한 얼굴·머리 마스크 좌표는 원작 픽셀로 완전히 잠근다.
- 머리는 원작처럼 전체 높이의 약 1/3인 5~6논리픽셀을 유지한다.
- 몸과 장비를 먼저 가운데에 작게 만든 뒤 남은 곳에 무기를 붙이지
  않는다. 생성 프롬프트 단계부터 머리, 몸, 무기를 같은 16×16 격자에
  함께 배치한다.
- 지팡이·창·검처럼 한쪽으로 뻗는 장비가 있으면 그 방향의 끝 3열을
  장비 전용 공간으로 먼저 예약한다.
- 양쪽에 장비가 있는 클래스는 실루엣 너비 15~16칸을 목표로 한다.
  장비가 없는 쪽도 소매·망토·견갑으로 자연스럽게 균형을 잡는다.

오른쪽 지팡이 캐릭터의 기본 배치는 다음과 같다.

| 요소 | 권장 논리 좌표 |
|---|---|
| 몸통·로브 중심 | x=4~11 |
| 오른쪽 소매 | x=10~12 |
| 손·손목 | x=12~13 |
| 보석·지팡이 머리 | x=13~15 |
| 지팡이 축 | x=14 또는 x=15 |
| 지팡이 아래 끝 | 발과 같은 y=15 기준선 |

왼손 장비는 위 좌표를 좌우 반전해 적용한다. 쌍검·넓은 견갑처럼 양쪽을
쓰는 클래스는 x=0~2와 x=13~15를 각각 한쪽 장비에 배정한다.

## 2. AI 원화 생성 규칙

프롬프트에는 아래 항목을 명시한다.

- `exact logical 16x16 grid`
- `uniform large square pixel blocks`
- `one complete centered character, fully inside canvas`
- 순수 `#ff00ff` 단색 배경
- 원작과 같은 머리 크기와 사용자 마스크의 얼굴·머리 고정
- 손, 장비 머리, 장비 축이 사용할 정확한 x 좌표
- 무기와 손, 보석과 축이 끊기지 않게 연결
- 끝 3열을 비워 두지 않고 실제 불투명 픽셀로 사용
- 잘림, 앤티앨리어싱, 그라데이션, 미세 픽셀, 글자, 그림자 금지
- 메가드라이브 4bpp에 맞는 단순한 색과 큰 색면

AI가 `#ff00ff`를 정확히 지키지 않고 가장자리에 어두운 보라색을 만들 수
있다. 캔버스 테두리와 연결된 마젠타·보라 계열은 밝기와 무관하게 모두
배경이며 캐릭터 팔레트나 실루엣으로 채택하지 않는다. 해당 클래스가
보라색 장비를 사용하지 않는다면 몸과 장비 사이에 둘러싸인 영역까지
마젠타·보라 키 계열을 원화 전체에서 제거한다.

AI 원화가 멋있어 보여도 머리가 작거나 무기가 캔버스 밖에서 잘렸다면
채택하지 않는다. 16×16 축소에서 새 디테일이 생기지 않으므로 원화
단계에서 이미 실루엣과 장비가 논리픽셀 단위로 읽혀야 한다.

## 3. 16×16 변환 규칙

- 순수 마젠타 배경을 제거한 뒤 전경 전체의 경계 상자를 구한다.
- 세로로 긴 지팡이 때문에 일반 비율 유지 축소가 가로 12~14칸만
  사용하게 만드는지 먼저 확인한다.
- 장비가 양옆 공간을 쓰도록 설계된 원화는 전경의 좌우 끝점을
  논리 x=0과 x=15에 최근접 대응한다. 평균 보간은 사용하지 않는다.
- 얼굴·머리는 가로 확대 결과를 쓰지 않고 마지막 단계에서 사용자
  마스크의 원작 픽셀을 같은 좌표에 다시 복원한다.
- 장비색은 클래스 식별에 필요한 보라색·녹색·금색 등을 보존한 채
  투명색을 제외한 최대 15색으로 줄인다.
- 원작에 순수 검정이 없다면 `(0,0,0)`을 새 외곽선색으로 쓰지 않는다.
  기본 외곽선은 원작 먹색 `(36,36,36)` 또는 해당 원작의 가장 어두운
  색을 사용한다.
- 각 RGB 채널은 메가드라이브 안전 단계
  `0, 36, 73, 109, 146, 182, 219, 255` 중 하나를 사용한다.
- 발, 로브 밑단, 지팡이 끝은 y=15 기준선에 맞추고 어느 방향도
  캔버스 밖에서 자르지 않는다.

## 4. 저장 전 필수 픽셀 검증

오른쪽 장비 캐릭터는 최종 16×16에서 다음을 모두 확인한다.

- x=13, x=14, x=15 각각에 불투명 픽셀이 있다는 것만으로 통과시키지
  않는다. 고립된 1픽셀이나 배경 프린지는 공간 활용으로 계산하지 않는다.
- 세로 지팡이는 x=15의 외곽선과 x=14의 축이 장비 머리 아래부터
  y=15까지 연속되어야 하며, x=15는 최소 10행 이상 실제 장비가 차지한다.
- 손·장비 가독성이 필요한 y 구간에서 오른쪽 4열 x=12~15의 점유
  픽셀이 충분하다.
- 지팡이 축은 보석 아래부터 발 기준선까지 같은 색군 또는 외곽선으로
  연속해서 읽힌다.
- 소매-손-지팡이와 보석-축이 의도하지 않게 분리되지 않았다.
- 전체 불투명 경계 상자의 오른쪽 끝이 `right=16`이다.
- 얼굴·머리 마스크의 모든 픽셀이 원작과 정확히 같다.
- 눈의 검은 픽셀과 그 왼쪽 흰자 픽셀도 원작 좌표·색 그대로다.
- 투명색 제외 15색 이하이며 모든 색이 메가드라이브 채널 단계에 있다.
- 원작에 없는 순수 검정과 캔버스 테두리에서 유입된 마젠타·보라색이
  최종 팔레트에 0개인지 확인한다.

왼쪽 장비는 x=0, x=1, x=2와 `left=0`을 같은 방식으로 검사한다.
좌우 장비 클래스는 양쪽 검증을 모두 통과해야 한다.

## 5. 비교와 채택 순서

1. 원작 전체 비율과 사용자 마스크만 레퍼런스로 AI 원화를 만든다.
2. 머리 크기, 손과 장비 위치, 잘림을 원화에서 먼저 검사한다.
3. AI 원화, 마젠타 제거 전경, 최종 16×16, 원작을 한 비교 이미지에
   배치한다.
4. 최종 16×16의 열별 불투명 픽셀 수와 팔레트를 자동 검사한다.
5. 비교 이미지에서 장비가 읽히고 자동 검사를 통과한 결과만 에디터에
   반영한다.

에디터에서 사용자가 수정한 디자인은 클래스별 오버라이드로 저장한다.
전체 재생성 시에도 이 오버라이드를 마지막에 적용해 수동 수정이
초기화되지 않게 한다.
