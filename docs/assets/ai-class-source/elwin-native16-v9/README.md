# Elwin native16 v9

v8 피드백 중 세 클래스를 수정한 현재 적용 묶음이다.

- `04 Lord`: 사용자가 좋아한 v8 형태를 그대로 편집 대상으로 사용하고,
  회색 갑옷만 청은색·남색·소량의 금색으로 변경했다.
- `0C Highlander`: v8 말을 폐기하고 원작 전체 비율과 사용자 마스크
  두 장만으로 새로 생성했다. 꼬리, 몸통, 비스듬한 목, 귀, 주둥이,
  다리와 굽이 구분되는 옆모습 말을 채택했다.
- `13 Mage`: v8의 넓은 로브 형태를 유지하면서 칙칙한 남색을
  로열블루·코발트·보라·은색으로 밝게 편집했다.
- 나머지 7개 클래스는 승인된 v8 원화를 유지했다.

## 검증

- AI 원출력 머리 일치율: 90.4~100%
- 수정한 로드: 94.2%
- 수정한 하이랜더: 93.3%
- 수정한 메이지: 97.1%
- 머리에 연결된 몸·장비: 67~98논리픽셀
- 마스크 고정 후 모든 정체성 픽셀: 원작과 100% 일치

## 파일

- `raw/`: 채택한 이미지 생성·편집 원출력
- `logical16/`: 16×16 변환 및 사용자 마스크 완전 고정본
- 루트 클래스 PNG: 에디터 입력용 nearest-neighbor 확대본
- `elwin-v9-raw-ai-contact-sheet.png`: 원출력 10개 합본
- `elwin-v9-contact-sheet.png`: 마스크 고정 후 10개 합본
- `elwin-v9-ai-final-rom.png`: AI 원화·최종 16×16·ROM 비교 합본
- `comparisons/`: 클래스별 비교 이미지
- `validation-report.json`: 자동 검증 결과

최종 이미지 생성·편집 지시는 `PROMPTS.md`에 기록했다.
