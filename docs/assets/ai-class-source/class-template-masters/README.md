# 클래스 디자인 템플릿 정책

완성도가 높은 16×16 클래스 디자인을 공통 장비·실루엣 템플릿으로 삼고,
대상 캐릭터에는 현재 보이는 얼굴·머리 픽셀과 원본 클래스 팔레트를
적용한다. 머리 마스크 안의 투명 좌표는 다시 지우지 않고 방패·견갑·무기
디자인을 우선해 긴 머리 마스크가 장비 외곽을 잘라내지 않게 한다.

현재 활성 템플릿은 다음과 같다.

- 엘윈 하이로드 → 파이터 계열의 변경 가능한 로드 클래스
- 레스터 아크메이지 → 아크메이지 상위 중복 클래스
- 헤인 메이지 → 메이지 상위 중복 클래스
- 헤인 프리스트 → 프리스트 상위 중복 클래스
- 헤인 하이프리스트 → 하이프리스트 상위 중복 클래스
- 헤인 하이로드 → 엘윈을 포함한 하이로드 클래스
- 헤인 소드마스터 → 엘윈을 제외한 소드마스터 클래스

`protected/`에는 엘윈·헤인 하이로드와 엘윈·헤인 소드마스터 기준본을
그대로 저장한다. 엘윈의 기존 하이로드 기준본은 로드 템플릿으로 재배치하고,
라이브 엘윈 하이로드에는 헤인 기준을 적용한다. 엘윈 소드마스터는 예외로
유지하며 네 기준 파일 자체와 기존 에디터 저장 이력은 덮어쓰거나 삭제하지
않는다.

보호 키와 활성 대상의 기계 판독 기준은
`editor/ai_class_template_policy.json`에 있다.

장비 우선 규칙과 원본 팔레트 보정 전 `v44` 결과는
`archive/shared-templates-before-original-palette-v1/`에 보존한다.
