# 엘윈 하이로드 기반 로드 공통 템플릿 v1

사용자가 편집해 승인한 엘윈 하이로드 `1:0B`의 갑옷·방패·무기·실루엣을
엘윈을 포함한 변경 가능한 로드 `04`에 적용한다. 엘윈에서는 기존
하이로드 디자인이 그대로 로드 디자인이 된다.

로드가 같은 스프라이트 묶음의 첫 원본 클래스인 경우에는 변경하지 않는다.
따라서 초기 클래스가 파이터이고 `파이터 → 로드` 순서가 되는 엘윈·쉐리·
스코트·키스·아론이 적용 대상이다. 리아나·라나·헤인·제시카의 로드는 원본
유지 대상이며, 레스터는 로드 클래스가 없다.

대상별 보이는 얼굴·머리 픽셀과 원본 로드 팔레트를 적용하고, 머리 마스크의
투명 좌표에서는 장비를 우선한다. 엘윈의 기존 하이로드 디자인과 대상의
기존 로드 디자인은 삭제하지 않고 각각 보호 폴더와 archive에 보관한다.
엘윈 `1:04`의 망토는 원본 엘윈의 선명한 빨강과 맞춘다.
오른쪽 방패는 현재 하이로드의 둥근 5픽셀 폭 실루엣과 파랑·금색 격자
명암, 황금빛 외곽을 같은 방식으로 사용한다.
아론 `8:04`는 왼쪽 아래 망토를 황토색으로, 오른쪽 큰 방패를
파랑·하늘색으로 분리해 두 부품의 외곽이 겹쳐 보이지 않게 한다.
