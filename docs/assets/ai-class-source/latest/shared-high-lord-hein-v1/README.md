# 헤인 하이로드 공통 템플릿 v1

사용자가 편집해 승인한 헤인 하이로드 `5:0B`의 장비·방패·무기·실루엣
좌표를 하이로드 공통 기준으로 사용한다.

엘윈을 포함해 하이로드가 있는 엘윈·리아나·라나·쉐리·헤인·스코트·키스·
아론·제시카에 현재 보이는 얼굴·머리 픽셀과 각 원본 클래스의 주색을
적용한다. 엘윈의 기존 하이로드 디자인은 로드 `1:04`의 기준으로 재배치하고
보호 원본과 에디터 저장 이력도 그대로 보존한다. 얼굴 마스크의 투명
픽셀에는 장비를 유지해 리아나·라나의 긴 머리 마스크가 방패 외곽을 지우지
않게 한다. 헤인 `5:0B`의 실제 적용본은 원본 로드와 아크메이지의 색상
일관성을 위해 마스터의 빨간 망토를 밝은 연두색으로 바꾼다. 보호 마스터의
빨간 버전은 수정하지 않는다.
엘윈 `1:0B`는 원본 엘윈 망토와 같은 선명한 빨강을 사용한다.
아론 `8:0B`의 방패와 청색 장비는 아론 나이트의 밝은 하늘색·중간
파랑 계열을 사용한다.
제시카 `10:0B`는 헤인의 파랑·금색 갑옷과 방패 실루엣을 다시 적용하고,
마스터의 빨간 망토만 밝은 하늘색·파랑·진한 파랑 3단 명암으로 바꾼다.
제시카의 얼굴·머리는 원본 좌표로 합성한 뒤 최종 에디터 이미지에서
오른쪽으로 한 칸 이동해 옷 중심과 맞춘다.
라나 `3:0B`는 라나 원본 하이로드의 색을 그대로 기준으로 삼는다. 갑옷의
넓은 면은 하늘색, 갑옷 음영은 원본의 중간 파랑, 망토는 중간 파랑과
진한 파랑으로 분리한다. 양쪽 발·부츠의 회색 7픽셀은 현재 저장본처럼
회색으로 유지한다.
