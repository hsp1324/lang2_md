# ROM 기마·드래곤 색상 변형 v1

AI로 다시 그린 상위 기마·드래곤 실루엣을 폐기하고 각 캐릭터의 원본
ROM 16×16 좌표로 복원했다. 말 기마 26개와 서펜 상위직 2개는 사용자
탈것 마스크 안의 명암만 변경하며, 드래곤 5개는 원본 몸·날개 색 역할만
변경한다.
기수 얼굴·머리, 흰 검날·창날·갑옷과 전체 알파 실루엣은 ROM과 같다.

- 전체 비교: `all-rom-mount-and-dragon-variants.png`
- 픽셀 검증: `validation-report.json`

검증 대상 33개 모두 알파 일치, 흰 무기 변경 0픽셀이다. 기마 클래스의
변경 픽셀은 전부 탈것 마스크 안에만 있다.

스코트 드래곤 로드는 쉐리 드래곤 로드와 같은 갈색·금색 용 명암을 써서
파란 드래곤 나이트와 분리한다. 키스는 파란 드래곤 나이트에서 보라색
드래곤 로드, 진홍·금색 드래곤 마스터로 올라갈수록 색 대비가 강해진다.

레스터 서펜 계열은 사용자가 편집한 서펜로드 탈것 마스크 126픽셀을 같은
원본 좌표의 서펜 나이트·마스터에 공유한다. 원본 파란 서펜 나이트를
기준으로 서펜로드는 자주·보라, 서펜마스터는 진홍·빨강으로 바뀌어
올라갈수록 따뜻하고 강한 색감이 된다.

리아나·라나는 팔라딘과 실버나이트의 말도 서로 다른 계열이다. 팔라딘은
리아나 진홍·라나 왕청, 실버나이트는 리아나 자주빛 적색·라나 청록빛
하늘색으로 분리한다.
