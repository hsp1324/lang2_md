# 최근 요청 클래스 캐릭터별 개선 v2

이번 폴더는 사용자가 방금 언급한 여섯 클래스만 다시 설계한다.

- 위저드 15: 사용자 승인 헤인 위저드 공유본 복구, 허리 투명 2픽셀 제거
- 하이프리스트 16: 사용자 승인 헤인 하이프리스트 공유본 복구,
  아론 고유 원본 유지
- 세이지 18: 리아나·라나 승인형 및 캐릭터별 최적형을 기준으로
  왼쪽 책·밝은 로브·오른쪽 링 지팡이 정리
- 서머너 28: 왼쪽 두루마리·닫힌 로브·오른쪽 수정 지팡이 정리
- 에이전트 25: 중갑 공통형을 버리고 중립색 망토·수정·세장 지팡이로 재픽셀화
- 자베라 26: 단색 중갑형을 버리고 닫힌 암보라 로브·왼손 마법·오른쪽
  삼지 지팡이로 재픽셀화

힐러 08은 사용자가 승인한 v1 형태를 보존한다. 키스 `7:08`만 이후
로드·세인트 계열과 통일하기 위해 초록 장비 면을 파랑·하늘색으로
재배색하며, 얼굴·흰 로브·금색 장식은 유지한다.
현재 리아나·라나 `2:08`, `3:08`은 이 넓은 기준보다 나중에 등록되는
`shared-liana-lana-healer-v1`의 최신 사용자 편집형을 사용한다.
리아나/라나는 같은 장비 좌표에서 적색/청색만 대비하고, 다른 캐릭터는
각자의 기존 대표 팔레트를 포인트 색으로 사용한다.

제시카 자베라·서머너의 이전 생성 기준은 승인된 마법 클래스의 얼굴
배치를 사용했다. 현재 본편 자베라는 사용자가 새로 저장한 90픽셀 목적지
마스크를 직접 적용하며, 별도 오른쪽 이동은 하지 않는다.
