# 엘윈 소드마스터 기반 하이마스터 공유 v1

엘윈 소드마스터의 쌍검·견갑·몸통 실루엣을 쉐리와 아론 하이마스터에
공유한다. 쉐리는 남청·청록·하늘색, 아론은 남색·파랑·하늘색으로
재배색하고 각 캐릭터의 원본 얼굴·머리·눈을 복원한다.

엘윈 얼굴 마스크에 잘못 포함돼 있던 왼쪽 견갑 10픽셀은 장비로 우선
처리한다. 따라서 쉐리·아론 모두 양쪽 견갑과 쌍검이 남는다. 아론 망토
그림자는 배경처럼 보이던 진한 남색 대신 식별 가능한 파랑 `#2449DB`를
사용하고, 쉐리의 청록 망토 명암은 그대로 유지한다.
아론 머리 왼쪽 `(1,2)`에 떨어져 있던 청록 장비 1픽셀은 투명 처리한다.

쉐리는 엘윈의 양쪽 아래 칼 좌표를 흰색·회색 금속 그대로 사용하고,
양쪽 견갑은 흰색·금색 장식으로 고정한다. 청록 재배색은 망토와 천에만
적용해 칼날·견갑·망토의 재질이 16×16에서도 분리된다.
