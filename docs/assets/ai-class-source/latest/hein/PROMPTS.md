# 헤인 상위 중복 클래스 11종 전면 재설계

## 입력

각 클래스는 이전 AI 원화나 장비 디자인을 입력하지 않고 아래 두 이미지만
사용해 OpenAI 이미지 생성으로 개별 신규 생성했다.

1. `logical16-v3-guides/hein/XX-original-full-ratio.png`
2. `logical16-v3-guides/hein/XX-masked-identity.png`

대상은 `09, 0A, 0B, 13, 14, 15, 16, 18, 19, 1A, 28` 11종이다.
기본 클래스와 중복되지 않는 원작 클래스는 변경하지 않는다.

## 공통 AI 프롬프트 기준

- 실제 출력 해상도는 크지만 정확한 논리 16열×16행의 균일한 큰
  사각 픽셀 블록으로 디자인
- 원작과 같은 큰 머리, 파란 머리 실루엣, 얼굴 방향과 눈 위치
- 머리는 전체 높이의 5~6논리픽셀
- 머리카락은 y=0, 발·로브 밑단·무기 끝은 y=15 사용
- 망토·방패·소매는 x=0, 무기·지팡이는 x=13~15 사용
- 16개 행과 16개 열을 모두 실제 머리·옷·갑옷·망토·무기로 점유
- 프레임, 고립된 채움점, 그림자, 배경 프린지로 가장자리를 채우지 않음
- 순수 `#ff00ff`는 배경 전용
- 캐릭터에는 마젠타·보라 프린지와 순수 검정 사용 금지
- 메가드라이브 4bpp용 최대 15색, 큰 색면과 단순한 장비 형태
- 앤티앨리어싱·그라데이션·미세 픽셀·글자·잘림·탈것 금지

### 소서러 단독 재생성

소서러 `09`는 원본·사용자 마스크만 다시 입력해 단독 재생성했다.
파란 로브를 넓고 연결된 색면으로 단순화하고, 오른쪽 끝에는 위아래로
이어지는 굵은 금갈색 지팡이와 청백색 수정을 배치했다. 머리와 얼굴
68픽셀은 기존 사용자 마스크대로 원작 픽셀을 복원한다.

### 프리스트·샤먼 디자인 교환과 팔라딘 수정

헤인에 한정해 클래스 ID와 능력치는 그대로 두고 캐릭터 디자인만
교환했다. 사용자가 직접 수정한 샤먼 `0A` 디자인은 프리스트 `11`에
배치하고, 기존 프리스트 디자인은 샤먼 `0A`에 배치했다. 두 클래스
모두 해당 클래스의 헤인 머리·얼굴 픽셀을 다시 복원한다.

팔라딘 `19`는 잘못 생성된 보병 시안을 폐기하고, 원본과 58픽셀 사용자
마스크만 입력해 갈색 군마에 탄 백은색 기병으로 새로 생성했다. 사람
머리는 하나의 연결된 형태로 유지하고 말 머리·몸·네 다리가 16×16에서
구분되도록 단순화했다.

## 16×16 변환

마젠타와 모든 어두운 보라 프린지를 제거하고 전경 경계만 잘라낸 뒤,
논리 16×16 전체에 셀 중심 최근접 샘플링으로 배치한다. 얇은 무기 끝
때문에 첫 샘플의 가장자리가 빠지면 남은 전경 범위를 한 번 더 16×16
전체에 맞춘다.

그 뒤 사용자 얼굴·머리 마스크를 원작 픽셀로 복원하고 메가드라이브
채널 단계의 최대 15색으로 제한한다. 최종 16개 행 또는 16개 열 중
하나라도 완전히 비면 빌드를 실패시켜 에디터에 게시하지 않는다.
