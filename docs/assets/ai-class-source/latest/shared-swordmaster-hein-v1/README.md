# 헤인 소드마스터 공통 템플릿 v1

사용자가 편집해 승인한 헤인 소드마스터 `5:1A`의 갑옷·쌍검·실루엣
좌표를 소드마스터 공통 기준으로 사용한다.

엘윈 소드마스터 `1:1A`는 제외하고 현재 디자인을 그대로 보호한다.
소드마스터가 있는 나머지 헤인·키스·아론·제시카에는 현재 얼굴 마스크와
원본 클래스 팔레트를 적용한다. 얼굴 마스크의 투명 좌표에서는 쌍검과
갑옷 픽셀을 우선한다.

아론 소드마스터는 회색 의상 대신 진청 `#2449DB`, 파랑 `#496DFF`,
하늘색 `#6DDBFF` 명암을 사용해 아론 하이로드·하이마스터와 색 계열을
공유한다. 은색 쌍검과 얼굴·머리 색은 바꾸지 않는다.

키스 소드마스터는 사용자가 다시 저장한 66픽셀 머리 마스크로 얼굴·머리를
재복원하며, 기존 금갈색 갑옷·쌍검 색감은 유지한다.
