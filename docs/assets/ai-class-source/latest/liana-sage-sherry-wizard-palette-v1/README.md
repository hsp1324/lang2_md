# 리아나 세이지·쉐리 위저드 밝은 재료색 보정 v1

- 리아나 세이지 `2:18`: 몸통 갑옷 내부의 순암색 21픽셀을 기존 장미색과
  적색 명암으로 변경했다.
- 쉐리 위저드 `4:15`: 사용자의 최신 편집 형태를 기준으로 망토 내부
  순암색 31픽셀을 청록·하늘색 명암으로 변경하고, 기존 보라색 로브
  44픽셀은 짙은 청록으로 바꿨다. 쉐리 메이지·아크메이지와 같은 색
  계열을 사용한다.

얼굴 마스크, 무기, 투명 실루엣과 외곽선용 어두운 픽셀은 바꾸지 않는다.
두 결과 모두 15색 이하, 빈 행·열 없음, 순검정 배경색 없음 검증을
통과해야만 에디터에 적용된다.
