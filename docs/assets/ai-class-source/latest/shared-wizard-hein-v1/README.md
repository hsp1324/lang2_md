# 헤인 위저드 복장 공유 v1

헤인의 위저드 옷·지팡이·실루엣을 위저드가 있는 모든 캐릭터에 공유한다.
각 캐릭터의 원본 얼굴·머리·눈은 그대로 복원하고 로브 팔레트만 바꾼다.
리아나·라나는 같은 형태의 빨강/파랑 대비, 쉐리는 남청·청록, 키스는
남청·금색, 레스터는 보라색, 제시카는 자주·연보라 계열을 사용한다.
