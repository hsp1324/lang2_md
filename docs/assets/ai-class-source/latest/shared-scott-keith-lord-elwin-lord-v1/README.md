# 현재 엘윈 로드 방패 기반 쉐리·스코트·키스 로드 v1

쉐리·스코트·키스 로드의 기존 얼굴·몸통·목 경계 보정은 그대로 유지하고,
오른쪽 `x=11..15`, `y=8..15` 방패 영역만 현재 사용자 편집 엘윈 로드에서
색 역할 그대로 가져왔다. 둥근 방패 외곽과 격자 위치는 같지만 쉐리는
남청·청록·하늘색·금색, 스코트는 숲초록·연두·금색, 키스는
남청·파랑·하늘색을 사용한다. 세 캐릭터의 망토와 몸통 큰 면도 같은
계열로 재배색해 작은 화면에서도 구분된다.

적용 전 스코트·키스 로드는 `archive/before-elwin-lord-shield/`에, 현재
엘윈 로드 기준본은 `master/`에 보존한다.

- 최종 논리16: `logical16/`
- 최근접 확대: `previews/`
- 세 캐릭터 비교: `all-lord-shields.png`
- 얼굴·방패·팔레트 검증: `validation-report.json`
