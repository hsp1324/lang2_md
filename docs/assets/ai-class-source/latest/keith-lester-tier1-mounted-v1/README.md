# 키스·레스터 1단 전용 탈것 디자인

- 키스 `01`은 원작 키스 `06` 호크나이트의 16×16 좌표를 그대로 사용한다.
- 키스 `06` 호크로드는 같은 좌표에서 탈것의 갈색 면만 적·금색으로 강화한다.
- 레스터 `01`은 원작 레스터 `07` 크로코나이트의 16×16 좌표를 그대로 사용한다.
- 레스터 `07` 크로코로드는 같은 좌표에서 탈것의 녹색 면만 붉은 계열로 강화한다.
- 얼굴과 탈것 마스크를 각각 JSON으로 보관해 New 클래스 에디터에서 다시 칠할 수 있다.
- 무기, 얼굴, 기수, 투명 배경의 좌표는 상위 색상 변형에서도 유지한다.

재생성: `python3 tools/build_keith_lester_tier_mount_variants.py`
