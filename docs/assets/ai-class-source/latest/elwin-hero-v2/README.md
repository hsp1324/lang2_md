# 엘윈 히어로 v2

엘윈 히어로 `22`를 원작 전체와 현재 사용자 얼굴 마스크만 기준으로 새로
디자인한 작업물이다. 외소하지 않은 넓은 백은·왕청 중갑 몸통, 금장 견갑,
짧은 진홍 망토와 손에 연결된 대형 히어로 검을 사용한다.

- `raw/22-hero-v1.png`: 첫 AI 시안. 작은 세부 픽셀이 많아 폐기했다.
- `raw/22-hero-v2.png`: 16논리칸으로 단순화한 채택 AI 시안.
- `raw/22-hero-final-locked.png`: 현재 마스크와 가장자리까지 고정한
  최종 AI 원화.
- `22-hero.png`: 에디터 참고용 1024×1024 최근접 확대본.
- `logical16/22-hero.png`: 실제 빌드 입력용 16×16 원화.
- `guides/`: 원작 전체와 현재 사용자 얼굴 마스크.

최종 논리16은 16개 행·열을 모두 사용하고 가시색 11색이며, 얼굴 마스크
73/73픽셀이 원작과 일치한다. 완전 검정이나 보라색 배경 오염이 없다.
