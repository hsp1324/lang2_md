# 엘윈 히어로 v2 생성 기준

Codex 내장 이미지 생성의 정체성 보존 편집 모드를 사용했다.

원작 전체 비율과 현재 `73`픽셀 얼굴 마스크만 최초 입력으로 사용했다.
이전 엘윈 히어로 AI 이미지는 최초 생성 입력으로 쓰지 않았다. 큰 머리를
같은 좌표로 유지한 채 넓고 단단한 보병 히어로 몸통, 백은·왕청 판금,
금장 견갑, 짧은 진홍 망토, 손·손잡이·날이 연결된 대형 검을 요청했다.

첫 시안은 몸과 검의 미세 픽셀이 많아 폐기했다. 두 번째 시안에서 장비를
정확한 16논리칸으로 단순화하고, 최종 원화에서 현재 얼굴 마스크를 완전히
고정했다. 축소 후 비었던 양 끝 열은 기존 검과 망토를 같은 색으로 한 칸
연장해 16개 행·열 전체를 사용하게 했다.
