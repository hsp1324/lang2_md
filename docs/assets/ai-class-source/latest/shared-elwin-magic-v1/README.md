# 엘윈 리터칭 메이지·아크메이지 공통 템플릿

에디터에서 사용자가 마지막으로 저장한 엘윈 메이지 `13`과 아크메이지
`14`의 16×16 디자인을 별도 마스터로 고정했다. 모든 대상 캐릭터는 이
마스터의 옷·지팡이·어두운 얼굴/목 경계 좌표를 공유하고, 보이는 원작
머리·얼굴·눈 픽셀과 캐릭터별 클래스 색만 복원한다.

- 엘윈 마스터: `master/`
- 캐릭터별 최종 16×16: `logical16/`
- 최근접 확대본: `previews/`
- 전체 비교: `all-elwin-magic-variants.png`
- 좌표·얼굴·팔레트 검증: `validation-report.json`

헤인 메이지·아크메이지는 짙은 초록 `#246D00`, 중간 연두
`#24B624`, 흰색 명암을 공유한다. 제시카는 새 하이로드 얼굴 마스크를
메이지·아크메이지에도 사용하고, 최종 합성에서 머리·얼굴만 오른쪽 한
칸 이동한다. 장비는 자주 `#9249B6`에서 연보라 `#DB92FF`로 이어지는
망토 명암을 사용하되, 안쪽 로브는 남보라 `#49496D`와 은보라
`#9292B6`, 지팡이 보석은 청록·하늘색으로 분리한다. 보라색을 모든
장비 면에 덮지 않고 망토·안감·로브·보석의 재질 대비를 유지한다.

쉐리 메이지·아크메이지는 프린세스의 밝은 청록 포인트
`#6DDBFF`를 망토의 주색으로 사용하고, 중간 청록 `#006D92`는 접힌
부분의 명암으로만 사용한다. 망토 외곽과 몸·팔 경계는 `#242424`로
분리해 밝게 바꾼 뒤에도 형태가 흐려지지 않게 한다.

이 작업은 에디터 PNG만 바꾸며 ROM에는 적용하지 않는다.
