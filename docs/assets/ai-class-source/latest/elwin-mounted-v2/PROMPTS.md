# 생성 프롬프트 기록

두 클래스 모두 원작 전체, 얼굴 마스크, 탈것 마스크를 이미지 입력으로
사용했다. 밝은 마젠타는 투명 배경이며 캐릭터 색으로 사용하지 않도록
명시했다.

## 공통 핵심 제약

- 정확히 16열 × 16행의 동일 크기 정사각형 논리 픽셀
- 반 셀, 잔픽셀, 안티앨리어싱, 그라데이션, 질감 금지
- 원작의 큰 SD 머리 크기·위치와 탈것의 크기·자세·위치 유지
- 기수와 탈것을 하나의 연결된 실루엣으로 표현
- 모든 행·열 사용, 최대 15색, 완전 검정과 보라색 테두리 오염 금지
- 얼굴과 탈것 이외의 갑옷·옷·무기만 클래스업 디자인

## 하이랜더

은색 고지 기병 갑옷, 왕청색 망토·마갑 장식, 작은 진홍 띠, 절제된 금장,
이미지 왼쪽까지 닿는 긴 기병 창을 요청했다. 1차에서 나온 세부 잔픽셀을
2차 편집에서 제거하고 굵은 장비 실루엣으로 단순화했다.

## 실버나이트

밝은 백은 판금, 왕청색 천·마갑, 작은 붉은 띠, 금장, 이미지 왼쪽의 긴
기사 창과 이미지 오른쪽의 작은 방패·중장 견갑을 요청했다. 1차 후보를
다시 엄격한 16×16 논리 셀로 단순화한 2차 후보를 채택했다.

생성 모델이 얼굴과 탈것 픽셀을 완전히 동일하게 복사하지 못한 부분은
`normalize_elwin_mounted_ai_source.py`에서 사용자가 저장한 두 마스크를
기준으로 원본 픽셀을 최종 복원한다.
