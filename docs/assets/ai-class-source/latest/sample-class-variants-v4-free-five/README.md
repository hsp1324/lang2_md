# 제한 해제·중앙 정렬 클래스 디자인 5안 v4

샘플 클래스 탭의 5개 캐릭터·클래스 조합을 클래스별 5안, 총 25안으로
정리한 작업물이다. 최초 자유 생성 뒤 최근 요청에 따라 엘윈 히어로와
마법 계열의 기준형을 다시 조정했다.

현재 미확정인 엘윈 히어로와 리아나·라나·헤인·제시카 세이지만 샘플
목록에 남겼다. 힐러·위저드·하이프리스트·에이전트·자베러·서머너 및
스코트 세이지 등 확정되었거나 더 이상 비교가 필요 없는 행은 목록에서
제외했다. 기존 생성 원본은 삭제하지 않고 이 폴더에 보존한다.

- 엘윈 히어로: 엘윈 킹의 형태를 그대로 사용한 색상 5안
- 리아나·라나·헤인·제시카 세이지: 각 캐릭터 아크메이지의 형태를 그대로
  사용한 진홍·청색·녹색·보라·금색 계열 5안

유지하는 제한은 다음 세 가지뿐이다.

- 최종 논리 크기 16×16
- 투명색을 제외한 최대 15색
- 사용자가 저장한 얼굴·머리·눈과 맞닿은 어두운 경계 픽셀의 정확한 복원

다음 제한은 제거했다.

- ROM 디자인 70~85% 유지
- 원본 ROM 바운딩 박스와 크기
- 원본 ROM 팔레트 우선 사용
- 머리 방향·무기 쪽·기본 자세 유지
- 헬멧·탈것 금지
- 클래스 장비만 변경

ROM 전용 보드는 캐릭터 정체성과 메가드라이브 도트 문법 참고로만
사용했다. 자유 생성안은 몸 폭, 자세, 장비 쪽, 무기, 방패, 망토, 헬멧,
탈것, 팔레트와 전체 실루엣을 자유롭게 설계한다. 아크메이지 기반 마법
계열은 승인된 형태를 고정한 색상 연구이므로 실루엣 다양성 대신 장비색
분리도를 검증한다.

각 AI 후보는 5칸 가로 보드에서 분리한 뒤, 몸통이 있는 중앙 높이 구간의
픽셀 중앙값을 정사각형 중앙에 맞춘다. 긴 무기나 한쪽 망토가 외곽선을
늘려도 몸 중심은 움직이지 않는다. `centering-report.json`에 저장된 전체
25안의 가로 중심 오차는 최대 1픽셀, 세로 중심 오차는 최대 0.5픽셀이다.

- 전체 비교: [all-ai-and-logical16.png](all-ai-and-logical16.png)
- 캐릭터별 비교: `contact-sheets/commanders/`
- 클래스별 AI 원본: 각 그룹의 `ai/`
- 최종 16×16: 각 그룹의 `logical16/`
- 생성 프롬프트: 각 그룹의 `prompts/board.txt`
- 검증: [validation-report.json](validation-report.json)

25/25 후보의 크기·색 수·얼굴 경계·중앙 정렬 검증을 통과했다. 킹 기반
히어로 1개 그룹과 아크메이지 기반 세이지 4개 그룹은 모두 같은 형태를
유지하면서 색상 분리도 검증을 통과한다.
