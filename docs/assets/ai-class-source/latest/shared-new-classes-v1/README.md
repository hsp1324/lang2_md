# 신규 공통 클래스 AI 디자인 v1

원작 캐릭터와 현재 얼굴 마스크만 참조해 힐러 `08`, 하이프리스트 `16`,
세이지 `18`, 위저드 `15`, 서머너 `28`, 에이전트 `25`, 자베라 `26`의
공통 장비 원화를 새로 생성했다. 이전 클래스 AI 이미지는 입력하지 않았다.

- 7개 신규 원화를 고정 16셀로 읽고 33개 캐릭터별 16×16로 변환한다.
- 얼굴·머리·눈은 캐릭터별 현재 마스크로 복원한다.
- 리아나 적색, 라나 청색, 쉐리 청록, 헤인 녹색, 스코트 청색,
  키스 청록, 아론 하늘색, 레스터 보라·회색, 제시카 자주·연보라 장비
  계열을 사용한다.
- 모든 결과는 15색 이하이며 16개 행·열을 모두 쓰고, 순수 검정·자홍
  배경 픽셀을 포함하지 않는다.
- 자베라는 AI 원화 축소 중 배경으로 잘못 빠졌던 중앙 로브를 닫힌
  몸통으로 재구성해 맵 배경이 비치지 않는다.
- `identity-masks.json`은 최종 33개 얼굴 마스크를 에디터에 전달한다.

재생성: `python3 tools/build_shared_new_class_variants.py`
