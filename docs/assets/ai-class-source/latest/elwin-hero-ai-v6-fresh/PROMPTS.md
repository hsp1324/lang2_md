# 엘윈 히어로 v6 생성 프롬프트

## 신규 생성

원작 ROM 스프라이트와 현재 얼굴 마스크만 레퍼런스로 사용해, 실제
메가드라이브 전술 RPG의 16×16 맵 스프라이트를 생성한다. 얼굴·머리의
크기와 위치는 유지하고, 보병 히어로의 비대칭 3/4 자세, 이미지 왼쪽
위로 뻗는 단일 은색 대검, 은백 중갑, 제한된 금장, 남청 천, 오른쪽
진홍 망토를 사용한다. 정면 대칭 자세, 작은 몸, 두 번째 검, 오른쪽
세로검, 잘린 장비, 순수 검정과 자홍 피사체 픽셀은 금지한다. 배경은
단색 #FF00FF로 고정한다.

## 단순화 반복

직전 신규 후보의 정체성·비대칭 자세·왼쪽 단일 대검·갑옷·타바드·망토는
유지하고, 장식과 픽셀 밀도만 실제 16×16 논리 셀로 단순화한다. 몸통은
닫힌 한 덩어리여야 하고, 장비 경계에는 어두운 분리 픽셀을 사용하며,
검과 두 발을 캔버스 안에 완전히 넣는다.
