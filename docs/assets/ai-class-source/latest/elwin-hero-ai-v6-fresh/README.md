# 엘윈 히어로 AI v6

- 입력 레퍼런스는 원작 ROM 엘윈 히어로와 현재 1:22 얼굴 마스크뿐이다.
- 이전 AI 히어로 원화와 이전 16×16 장비 좌표는 새 생성 입력에서 제외했다.
- 선택한 신규 원화의 왼쪽 대각 대검, 비대칭 은백 견갑, 남청 타바드,
  오른쪽 진홍 망토를 실제 네이티브 16×16 군집으로 다시 픽셀화했다.
- 현재 얼굴·머리·눈 73픽셀은 원본과 정확히 같다.
- 단일 연결 실루엣, 10색, 빈 행·열 없음, 순수 검정·자홍 배경 없음,
  몸통 투명 구멍 없음을 검증한다.

재생성 명령: python3 tools/build_elwin_hero_ai_v6.py

최종 프롬프트는 PROMPTS.md에 기록했다.
