# 헤인 소서러 AI 디자인 v2

헤인 소서러 `09`를 에디터 전용으로 새로 만든 결과다. 실제 ROM에는
반영하지 않는다.

- `raw/hein-09-sorcerer-ai.png`: 내장 이미지 생성 결과 원본
- `clean/hein-09-sorcerer-ai.png`: 단색 자주색 배경을 제거한 AI 원본
- `logical16/hein-09-sorcerer-ai.png`: 에디터에 표시하는 최종 16×16
- `PROMPT.md`: 실제 생성 프롬프트와 레퍼런스 역할

이번 버전은 기존처럼 생성 몸체에 ROM 얼굴을 덮어씌우지 않는다.
현재 헤인 소서러의 확대 픽셀 얼굴·청색 머리를 첫 레퍼런스로, 승인된
헤인 메이지의 장비 문법을 두 번째 레퍼런스로 넣고 AI 생성 단계부터
같은 얼굴과 머리 형태를 요구했다.

최종본은 원본 비율을 유지한 채 피사체 전체를 16×16 안에 맞추고, 가장
긴 세로축은 16행을 전부 사용한다. 평균 보간은 쓰지 않았고 논리 픽셀을
최근접 방식으로 읽은 뒤 메가드라이브 채널값에 맞췄다. 투명색을 제외한
가시색은 15색이다.

에디터는 `source-originals/5-09.png`를 AI 디자인 원본으로 보여 주고
`5/09.png`를 최종 16×16으로 보여 준다. 프리스트 `11`과 하이프리스트
`16`도 각각 승인된 마스터를 `source-originals`에서 직접 보여 준다.
