# 쉐리 레인저 네이티브 16×16 v3

쉐리 하이마스터의 남청·청록·하늘색 팔레트와 체형을 전직 계열 기준으로
사용하되, 레인저는 한 단계 가볍게 정리했다. 왼쪽의 화려한 검 장식은
청록색 짧은 망토로 바꾸고 오른쪽에 한 자루의 흰 검만 남겼다. 몸통의
금색 면적도 줄여 하이마스터보다 단순하지만 16×16 공간은 빠짐없이 쓴다.

쉐리의 원본 단발 머리·얼굴·눈 74픽셀은 그대로 복원한다.
