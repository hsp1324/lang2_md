# 엘윈 로드 v2 생성 기준

Codex 내장 이미지 생성의 정체성 보존 편집 모드를 사용했다.

## 입력 역할

- `guides/04-original-full-ratio.png`: 원작 전체 16×16 좌표와 신체 비율.
- `guides/04-masked-identity.png`: 머리·얼굴·눈·흰자·머리카락을
  절대 고정하는 현재 사용자 마스크.
- 이전 엘윈 로드 AI 이미지는 최초 생성 입력으로 사용하지 않았다.

## 핵심 프롬프트

원작 머리를 같은 좌표와 크기로 유지하고, 말·안장·동물·기승 자세가 전혀
없는 보병 로드로 몸과 장비만 다시 그린다. 담청·왕청 지휘관 갑옷, 금장
견갑, 짧은 진홍 망토, 한손검과 청금색 소형 방패를 사용한다. 전체 그림을
정확한 16개 행·열의 큰 정사각형 논리픽셀로 단순화하며 모든 행과 열을
실제 캐릭터·장비가 사용한다. 배경은 정확한 `#FF00FF` 단색이고 캐릭터에는
보라색이나 완전 검정을 쓰지 않는다. 최대 15개 가시색, 계단식 메가드라이브
색상, 안티앨리어싱·그라데이션·미세 픽셀·프레임·텍스트를 금지한다.

첫 시안은 작은 세부 픽셀 때문에 폐기했다. 두 번째 AI 시안의 보병
실루엣과 장비를 채택한 뒤, 최종 AI 원화에서 사용자 마스크 69픽셀을
원작 값으로 완전히 고정하고 오른쪽 방패 가장자리를 16번째 열까지
연결했다.
