# 엘윈 로드 v2

엘윈 로드 `04`를 원작 전체와 현재 사용자 얼굴 마스크만 기준으로 새로
디자인한 작업물이다. 말이나 다른 탈것이 없는 보병 로드이며, 담청·왕청
갑옷, 금장 견갑, 짧은 진홍 망토, 한손검, 청금색 소형 방패를 사용한다.

- `raw/04-lord-v1.png`: 첫 AI 시안. 몸 장비에 논리칸보다 작은 픽셀이
  많아 폐기했다.
- `raw/04-lord-v2.png`: 16논리칸으로 단순화한 채택 디자인의 AI 원본.
- `raw/04-lord-final-locked.png`: 사용자 마스크 69픽셀을 정확히
  고정하고 배경 오염을 제거한 최종 AI 원화.
- `04-lord.png`: 에디터 참고용 1024×1024 최근접 확대본.
- `logical16/04-lord.png`: 실제 빌드 입력용 16×16 원화.
- `guides/`: 생성에 사용한 원작 전체와 현재 사용자 얼굴 마스크.

최종 논리16은 16개 행과 16개 열을 모두 사용하고, 가시색 15색이며,
완전 검정이나 보라색 배경·테두리 픽셀이 없다. 머리·얼굴·눈 마스크는
69/69픽셀 원작과 일치한다.
