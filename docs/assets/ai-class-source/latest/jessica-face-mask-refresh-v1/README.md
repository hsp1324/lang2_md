# 제시카 신규 클래스 얼굴 마스크 갱신 v1

에디터에서 사용자가 다시 저장한 최신 얼굴·눈 마스크를 다음 여섯 클래스에
원본 제시카 픽셀로 재합성한 결과다.

- `10:08` 힐러: 마스크 74픽셀
- `10:11` 프리스트: 마스크 74픽셀
- `10:15` 위저드: 마스크 74픽셀
- `10:18` 세이지: 마스크 74픽셀
- `10:1A` 소드마스터: 마스크 67픽셀
- `10:26` 자베라: 마스크 90픽셀

보이는 마스크 픽셀은 여섯 클래스 모두 ROM 원본과 전부 일치한다.
소드마스터는 이전 마스크에서 빠졌던 왼쪽·위쪽 머리카락 12픽셀을
원본에서 복원하고 과거 강제 오른쪽 이동을 제거했다. 세이지는 새로
추가된 회색 얼굴 경계 1픽셀을 복원했다. 위저드는
새 회색 경계 픽셀의 팔레트 슬롯을 확보하기 위해 장비에 1픽셀만 쓰인
`#2449FF`를 `#496DFF`로 합쳐 최종 15색을 유지한다. 자베라는 최신
목적지 마스크를 직접 사용하며 이전의 강제 오른쪽 이동을 적용하지 않는다.

- `logical16/`: 현재 적용 논리16
- `previews/`: 최근접 확대본
- `previous/`: 적용 전 에디터 디자인
- `all-jessica-face-mask-refresh.png`: 여섯 클래스 비교판
- `validation-report.json`: 마스크 일치와 팔레트 검증

재적용 명령:

```bash
python3 tools/apply_jessica_new_class_face_masks.py
```
