# 헤인 매직나이트 원본 기반 팔라딘

헤인 팔라딘 `19`의 AI 실루엣을 사용하지 않는다. 비-AI 매직나이트
`0D`의 기마 16×16 좌표를 그대로 사용하고, 현재 팔라딘 얼굴 마스크를
복원한다. 원본 말·기수·무기 좌표는 유지하며 장비와 하단 마갑만 짙은
초록·중간 연두·밝은 연두로 재배색했다.

- ROM 마스터: `master/hein-0D-magic-knight-rom.png`
