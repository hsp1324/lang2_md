기존 AI 원화는 변경하지 않았다. 원화의 주색인 짙은 보라색 망토가
최종 16×16에서 짙은 빨강으로 잘못 매핑된 부분만 다시 디자인했다.

- 짙은 빨강 38픽셀 → 메가드라이브 짙은 보라 `#49246d`
- 마젠타 장비 2픽셀 → 밝은 보라 `#6d2492`
- 마스크 밖 순수 검정 3픽셀 → 짙은 남보라 `#242449`
- 얼굴·머리 사용자 마스크 74픽셀 유지
- 금색 지팡이와 청색 마법 하이라이트 유지
- 가시색 15색 제한 유지

`logical16/15-wizard.png`가 에디터에 적용된 최종 디자인이다.
