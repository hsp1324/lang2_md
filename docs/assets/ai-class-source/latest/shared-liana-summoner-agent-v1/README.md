# 리아나 사용자 편집 서머너 기반 쌍둥이 클래스 v1

서머너는 사용자가 에디터에서 방금 저장한 리아나 서머너 `2:28`,
에이전트는 공통형 적용 전 보존한 리아나 에이전트 `2:25`, 자베라는
사용자가 만족한 색감의 리아나 자베라 `2:26`을 각각 별도 논리 16×16
마스터로 사용한다. 에이전트와 자베라는 최신 서머너의 중앙 80픽셀
머리·몸 배치를 반영하고 클래스별 외곽 장비와 하단 망토를 유지한다.
같은 클래스의 리아나·라나 사이에서만 픽셀 배치를 공유한다.

- `2:28` 리아나 서머너: 사용자 저장 주홍·금색 원본
- `2:25` 리아나 에이전트: 금발을 원형 그대로 잠그고, 보존된 별도
  디자인에 와인·자주 망토와 진홍 장식
- `3:28` 라나 서머너: 코발트·빙청
- `3:25` 라나 에이전트: 금발을 유지한 청록·민트색. 코발트·빙청
  서머너와 주색이 겹치지 않는다.
- `2:26` 리아나 자베라: 기존 자주·연보라 색감 유지
- `3:26` 라나 자베라: 에이전트의 청록과 겹치지 않도록 라나
  하이로드식 왕청·파랑·밝은 하늘색으로 변경

서머너·에이전트·자베라는 쌍별 투명 실루엣이 최소 7픽셀 달라 클래스별
형태가 구분된다. 각 완성 디자인에 예전 83~107픽셀 머리 마스크를 다시
덮지 않아 긴 머리 주변 장비가 사라지는 것을 막는다. 모든 결과는 같은
클래스 안에서만 실루엣·비의상 픽셀 일치, 15색 이하, 순검정·보라 배경색
없음과 빈 행·열 없음 검증을 통과해야 적용된다.
