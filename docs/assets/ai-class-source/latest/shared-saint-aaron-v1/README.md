# 아론 세인트 공통 디자인 공유 v2

에디터에서 사용자가 직접 수정한 아론 세인트 `08-17`의 제의·지팡이·
장비 픽셀을 세인트가 있는 엘윈·리아나·라나·쉐리·헤인·스코트·키스·
아론·제시카에 공유한다. 각 캐릭터의 원본 머리·얼굴·눈은 ROM에서 다시
복원하며, 의상은 엘윈/리아나 적색, 라나 청색, 쉐리 남청·청록, 헤인/스코트
녹색, 키스 청색, 아론 원본 금갈색, 제시카 자주·연보라 계열로 구분한다.

헤인·스코트·키스·제시카는 각 세인트에서 다시 저장한 최신 머리 마스크를
사용한다. 리아나는 같은 머리 좌표를 쓰는 라나 세인트의 79픽셀 마스크를
공유한다. 수동 마스크의 투명 좌표도 보호해 제의나 지팡이가 머리 안으로
침범하지 않는다.
