# 아론 사용자 편집 로드 기반 3인 로드 v1

에디터에서 사용자가 방패를 직접 다듬어 저장한 최신 아론 로드 `8:04`를
마스터로 고정했다. 쉐리 `4:04`, 스코트 `6:04`, 키스 `7:04`는 아론의
방패·갑옷·검·어두운 외곽선 좌표를 공유하고 각자의 원작 얼굴·머리·눈
마스크를 복원한다.

- 쉐리: 남청·청록·하늘색·금색
- 스코트: 숲초록·연두·금색
- 키스: 남청·파랑·하늘색

`master/`에는 최초 실행 시 캡처한 아론 저장본, `archive/`에는 적용 직전
세 캐릭터 디자인을 보존한다. `logical16/`이 에디터 및 재빌드에서 쓰는
승인 논리 16×16 소스다. 모든 결과는 얼굴 일치, 아론 장비 역할 좌표,
15색 이하, 순검정 없음, 빈 행·열 없음 검증을 통과해야만 적용된다.
