# 헤인 공통 클래스 템플릿 v1

사용자가 좋다고 지정한 헤인의 프리스트 `5:11`, 메이지 `5:13`,
하이프리스트 `5:16` 최종 16×16을 각 클래스의 공통 장비·실루엣
기준으로 사용한다. 대상 캐릭터는 같은 픽셀 좌표를 공유하고 현재 얼굴
마스크의 보이는 픽셀과 원본 클래스 주색을 적용한다. 얼굴 마스크의 투명
좌표는 장비를 지우지 않도록 방패·로브·지팡이 디자인을 우선한다. 아론
메이지는 아크메이지와 통일한 짙은 왕청색·중청색·하늘색 계열을 사용한다.

ROM 원본 유지 클래스에는 적용하지 않는다. 따라서 스코트 프리스트와
아론 하이프리스트처럼 해당 클래스가 기본 디자인인 경우 그대로 둔다.

- 사용자 승인 기준: `master/`
- 실제 입력: `logical16/`
- 전체 비교: `all-hein-template-variants.png`
- 검증: `validation-report.json`
