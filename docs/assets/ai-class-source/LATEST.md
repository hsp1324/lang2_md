## 하이마스터 장비 역할·세인트 얼굴·서펜 색 단계 보정 v80

쉐리 하이마스터는 기존 남청·청록·하늘색 색감을 유지하되 장비 역할을
다시 분리했다. 엘윈 소드마스터의 양쪽 칼 좌표는 흰색·회색 금속으로,
양쪽 어깨장식은 흰색·금색으로 고정하고, 망토와 천에만 청록 명암을
적용해 칼·견갑·망토가 서로 섞이지 않는다.

헤인·스코트·키스·제시카 세인트는 사용자가 다시 칠한 각 세인트 머리
마스크로 얼굴과 머리를 재복원했다. 라나 세인트의 새 79픽셀 마스크는
동일한 머리 좌표를 쓰는 리아나 세인트에도 복사했다. 아론 세인트의
제의·지팡이 형태와 캐릭터별 기존 색감은 그대로다. 키스 소드마스터도
새 66픽셀 머리 마스크로 다시 합성했다.

리아나 세이지는 방금 저장한 91픽셀 머리 마스크로 다시 복원했고, 동일한
머리 좌표의 라나 세이지에도 그 마스크를 복사했다. 세이지 두 클래스만
갱신해 기존 장비와 리아나 적색·라나 청색 대비는 유지했다.

레스터는 원본 파란 서펜나이트 다음에 자주·보라 서펜로드, 진홍·빨강
서펜마스터가 오도록 탈것 마스크 안의 색만 재조정했다. 기수·무기·원본
알파 좌표는 바꾸지 않는다.

## 공통 세인트·쉐리 레인저·캐릭터 팔레트 정리 v79

사용자가 편집한 아론 세인트의 제의·지팡이·장비 좌표를 세인트가 있는
9명 전원에게 공유했다. 각 캐릭터의 원본 머리·얼굴·눈은 복원하고,
엘윈/리아나 적색, 라나 청색, 쉐리 남청·청록, 헤인/스코트 녹색,
키스 청색, 아론 금갈색, 제시카 자주·연보라로 의상만 구분했다.

아론 소드마스터는 기존 회색 의상을 진청 `#2449DB` → 파랑 `#496DFF`
→ 하늘색 `#6DDBFF` 3단계로 바꿔 하이로드·하이마스터와 같은 전직 계열
색감을 사용한다. 은색 쌍검과 원본 얼굴은 그대로다.

제시카 메이지·아크메이지는 보라색 단색 덮기처럼 보이던 팔레트를
재구성했다. 자주 망토와 연보라 테두리는 유지하고, 안쪽 로브는 짙은
남보라 `#49496D`와 은보라 `#9292B6`, 지팡이 보석은 청록·하늘색으로
분리해 장비 면과 재질이 구분된다.

쉐리 레인저는 잘린 듯 작던 이전 디자인을 폐기하고 하이마스터의 체형과
남청·청록·하늘색을 잇는 네이티브 16×16로 다시 만들었다. 왼쪽은 짧은
청록 망토, 오른쪽은 한 자루의 흰 검으로 단순화해 하이마스터보다 한 단계
가벼운 전직 단계로 보이게 했다.

## 하이마스터 왼쪽 견갑 전체 길이 복원 v78

엘윈 소드마스터 얼굴 마스크에 장비로 잘못 포함된 견갑은 6픽셀이 아니라
10픽셀이었다. 빠져 있던 바깥쪽 하단 `(0,10)`, `(1,10)`, `(2,10)`,
`(0,11)`을 장비 우선 좌표로 추가해 쉐리·아론 하이마스터의 왼쪽 견갑을

## 쉐리 망토 음영·아론 하이마스터 단독 픽셀 보정 v77

쉐리 메이지·아크메이지에서 망토 뒷면을 윤곽선과 같은 `#242424`로
칠하던 매핑을 `#002449` 어두운 청록으로 바꿨다. 목·팔·장비 경계의
실제 윤곽선은 `#242424` 그대로라 맵 배경 누수 방지 효과는 유지하면서
망토 면만 어두운 배경에서 식별된다. 아론 하이마스터 머리 왼쪽 `(1,2)`의
마스크 밖 청록색 단독 장비 픽셀은 투명 처리했다.

## 공통 위저드·하이마스터 견갑·탈것 단계 보정 v76

헤인 위저드의 옷·지팡이·16×16 실루엣을 위저드가 있는 리아나·라나·
쉐리·키스·레스터·제시카에 공유했다. 얼굴·머리·눈은 캐릭터별 원본이며,
리아나/라나는 빨강/파랑, 쉐리는 남청, 키스는 남청·금색, 레스터는 보라,
제시카는 자주·연보라 팔레트다. 헤인 위저드 본인은 기준 디자인 그대로다.

제시카 하이로드는 오른쪽 1칸 목적지 마스크에 ROM의 왼쪽 원본 픽셀을
대응시켜 눈·머리가 잘리지 않게 했고, 하늘색 망토 20픽셀은 전직 전후와
같은 진홍·암적색으로 바꿨다. 제시카 소서러는 AI 형태를 폐기하고 ROM
원본 실루엣의 붉은 로브만 메이지·아크메이지와 같은 자주 계열로 바꿨다.

사용자가 방금 편집한 아론 세인트의 제의·지팡이 디자인을 쉐리 세인트에
옮겼다. 쉐리는 원본 단발 머리·얼굴·눈 70픽셀을 유지하고 의상만 공유한다.
엘윈 소드마스터 얼굴 마스크에 장비로 잘못 포함됐던 왼쪽 견갑 6픽셀은
장비 우선으로 바꿔 쉐리·아론 하이마스터 모두 양쪽 견갑·쌍검이 보인다.
아론 망토는 배경과 겹치던 진한 남색 대신 파랑 `#2449DB`로 밝히고,
쉐리 망토 색은 유지했다.

스코트 드래곤 로드는 쉐리와 같은 황금 용으로 바꿨다. 키스는 파란
드래곤 나이트 → 보라 드래곤 로드 → 진홍·금색 드래곤 마스터 순으로
강해지는 색 단계가 보이게 했다. 세 경우 모두 원본 ROM 드래곤·기수
좌표, 얼굴, 흰 무기는 그대로다.

레스터는 방금 편집한 서펜로드 탈것 마스크 126픽셀을 동일한 원본 좌표의
서펜 계열에 공유했다. 원본 파란 서펜 나이트 → 진한 왕청·자주 서펜로드
→ 보라·마젠타·선홍 서펜마스터 순서로 탈것 색 대비가 강해진다. AI로
그린 상위 실루엣은 사용하지 않고 원본 ROM 좌표와 기수는 유지한다.

리아나·라나의 말도 클래스별로 분리했다. 팔라딘은 리아나 진홍·라나
왕청을 유지하고, 실버나이트는 리아나 자주빛 적색·라나 청록빛 하늘색을
사용한다. 네 결과 모두 같은 사용자 탈것 마스크 안의 말 색만 바뀐다.

## ROM 기마·드래곤 복원과 공유 클래스 리터칭 v73

엘윈 히어로 `22`는 얼굴·머리 73픽셀과 대형 검을 유지하고 하단 갑옷,
왕청 흉갑, 금장, 진홍 망토를 큰 픽셀 면으로 정리한 네이티브 16×16
v3로 교체했다. 리아나 메이지 `13`은 망토의 베이지 장비색을 금색으로
분리해 지팡이 반대편 손 1픽셀이 망토와 합쳐지지 않는다.

현재 AI 실루엣을 쓰던 상위 기마 26개와 드래곤 5개는 원본 ROM
16×16 좌표로 돌아갔다. 기마는 사용자 탈것 마스크 안의 말 색만,
드래곤은 몸·날개 색만 클래스별로 다르다. 전체 31개는 ROM 알파와
일치하고 흰 검·창 변경은 0픽셀이며, 기마 변경 픽셀은 마스크 밖 0개다.

쉐리 아크메이지는 메이지와 같은 남청·청록 계열로 바꿨다. 쉐리·키스
위저드는 헤인 위저드 복장을 공유하고, 쉐리·아론 하이마스터는 엘윈
소드마스터의 쌍검·견갑 실루엣을 공유한다. 각 캐릭터 얼굴과 머리는
원본 마스크로 복원한다. 아론 로드는 사용자가 손본 검을 유지하고,
엘윈 로드형 파랑·하늘색 격자 방패를 장비 우선으로 다시 표시한다.

## 공통 클래스 어두운 경계 보정 v64

하이프리스트도 기존 방식으로 대상 캐릭터에 적용한다. 각 캐릭터의 현재
얼굴 마스크는 유지하고 장비 주색만 캐릭터별로 바꾼다. 레스터·헤인에
남아 있는 이전 아크메이지와 메이지 저장 이력은 삭제하지 않고 새 엘윈

같은 중간 연두 `#24B624`로 낮춘다.

헤인 하이로드와 헤인 소드마스터도 공통 템플릿으로 사용한다. 하이로드는
엘윈·리아나·라나·쉐리·헤인·스코트·키스·아론·제시카에 적용하고,
소드마스터는 엘윈의 별도 디자인을 보호한 채 헤인·키스·아론·제시카에
헤인 장비 좌표와 캐릭터별 색을 적용한다. 엘윈의 기존 하이로드 디자인은
엘윈 로드로 재배치한다.

제시카의 하이로드 `0B`와 소드마스터 `1A`는 공통 장비 중심보다 원본
머리·얼굴이 한 칸 왼쪽에 놓여 보이므로, 최종 합성 단계에서 보이는
머리·얼굴 픽셀만 오른쪽으로 한 칸 이동한다. 하이로드는 이동된 결과를
사용자가 다시 저장한 이전 편집 이력 대신 헤인 하이로드의 파랑·금색
갑옷·방패·검 실루엣을 다시 적용한다. 망토는 밝은 하늘색·파랑·진한
파랑의 3단 명암으로 바꾼다. 소드마스터도 합성 단계에서 머리만 이동한다.
갑옷·견갑·방패·검은 이동하지 않는다.

제시카 메이지 `13`과 아크메이지 `14`는 엘윈 리터칭 실루엣을 기준으로
사용한다. 방금 저장한 하이로드의 69픽셀 얼굴 마스크를 두 클래스에
복사하고, 장비 합성 뒤 머리·얼굴만 오른쪽 한 칸 이동한다. 청색 머리와
원본 눈은 유지하며 로브·망토는 자주·연보라 명암으로 바꾼다.

제시카 소드마스터 `1A`는 사용자가 저장한 오른쪽 1칸 머리 정렬과 현재
빨강·회청색 배색, 장검, 회색 부츠를 그대로 유지한다. 상체와 허리 사이의
빈 9행, 오른쪽 소매, 하단 망토 주름에서 끊겨 보이던 연결부만 소폭
보정한다. 보정 전 저장본은
`archive/jessica-swordmaster-before-polish-v1/`에 보존한다.

엘윈 소드마스터 `1A`는 사용자가 새로 그린 하단 망토 좌표를 보존하고
원작 엘윈 지휘관 망토와 같은 선명한 진홍색으로 보정한다. 엘윈 메이지
`13`과 아크메이지 `14`는 마지막 사용자 리터칭 결과를 각 클래스의 새
공통 마스터로 고정한다.

에디터 클래스 트리는 캐릭터당 대표 히든 경로 하나만 담은 10개 물리
전직 레코드와 별도로, 원작 캐릭터 전용 스프라이트 표에 있는 복수 히든
경로도 표시한다. 엘윈의 로얄나이트, 리아나·라나의 에이전트·자베라,
쉐리의 드래곤마스터·프린세스, 헤인·레스터의 자베라, 제시카의 서머너를
포함해 10개가 복원되어 전체 에디터 AI 자산은 180개다. 이 보조 히든
클래스는 캐릭터 전용 원작 16×16을 편집 가능한 초기값으로 사용하며,
실제 ROM 전직 레코드는 변경하지 않는다.

공통 템플릿의 머리 마스크는 `v45`부터 보이는 얼굴·머리 픽셀만 유지한다.
마스크 안의 투명 좌표에서는 장비를 지우지 않아 리아나·라나의 긴 머리
마스크와 겹치는 방패·견갑·무기 외곽을 보존한다. 재배색은 임의 고채도
색이 아니라 대상의 원본 클래스 팔레트를 사용한다. 하이로드도 리아나는
빨강·진홍 망토, 라나는 파랑·남청 망토를 사용해 두 자매의 색 대비를
유지한다. 라나 하이로드의 갑옷 넓은 면은 라나 원본의 하늘색, 음영은
원본 중간 파랑으로 다시 맞추고 망토는 중간 파랑·진한 파랑으로
분리한다. 양쪽 발·부츠의 회색 7픽셀은 유지한다. 리아나의 이전 파란
하이로드 편집본은 archive에 보존한다.

망토와 회색 방패가 겹쳐 보이지 않도록 망토를 황토색, 방패를 나이트와
같은 파랑·하늘색 계열로 분리했다. 메이지와 아크메이지는 기본 아론의
흰색·황토색 망토를 이어 가되 아크메이지는 흰색을 넓은 주면으로 쓰고
황토색을 주름·테두리에 남긴다. 지팡이의 파란 마력 효과는 유지한다.
하이로드의 방패와 청색 장비도 나이트 방패와 같은 하늘색 계열로
맞췄다. 아론 소드마스터는 사용자가 다시 저장한 얼굴
마스크로 얼굴 픽셀을 복원했다. 엘윈 로드와 하이로드의 망토는 원본
