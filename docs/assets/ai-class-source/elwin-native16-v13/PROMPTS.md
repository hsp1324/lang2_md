# Elwin v13 Swordmaster prompt

Codex 내장 이미지 생성의 정체성 보존 편집 모드를 사용했다.

## 입력 역할

- `1A-original-full-ratio.png`: 원작 전체 좌표·신체 비율 기준
- `1A-masked-identity.png`: 머리·얼굴·눈·머리카락 잠금 기준
- 현재 하이로드 16×16: 사용자가 지정한 금색 견갑 장비 스타일 기준

## 채택 프롬프트 요약

상단 8논리행과 모든 마스크 픽셀을 원작 좌표 그대로 복사하고
`y=8~15`만 편집한다. 남색·은색 경량 몸과 붉은 허리띠, 분리된 다리,
좌우 손에 연결된 쌍검을 유지한다. 목 양쪽 상완 위에 암금색 외곽,
금색 본체, 연노랑 강조색으로 구성된 대칭 2×2 또는 2×3 견갑을
추가한다. 견갑은 하이로드처럼 풍성하지만 머리·손·칼을 가리지 않고
소드마스터 몸 전체를 중장으로 만들지 않는다. `x=0`, `x=15`는 비우며
방패, 세 번째 무기, 망토, 탈것과 미세 장식을 금지한다.

첫 시안은 머리 62/69, 머리 보정 편집은 16/69라 폐기했다. 채택본은
64/69(92.8%)이며, 최종 변환에서 마스크 69픽셀을 원작으로 완전히
고정한다.
