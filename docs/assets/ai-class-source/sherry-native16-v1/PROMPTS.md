# Sherry native16 v1 prompts

Codex 내장 이미지 생성의 참조 이미지 편집 모드를 사용했다.

## 입력 역할

- `../sherry-head-ratio-guides-v1/NN-original-full-ratio.png`: 해당
  클래스의 원작 전체 좌표·크기·자세 기준
- `../sherry-head-ratio-guides-v1/NN-masked-identity.png`: 사용자가
  지정한 머리·얼굴·눈·흰자·단발 잠금 기준

이전 쉐리 AI 원화는 입력으로 사용하지 않았다.

## 공통 채택 프롬프트

첫 이미지를 새로 해석하거나 확대하지 말고 실제 16×16 논리격자에서
직접 편집한다. `y=0..8`과 두 번째 이미지의 모든 보호 셀을 원본 좌표
그대로 복사한다. 큰 얼굴, 눈·흰자, 턱선 길이의 은발 단발을 유지하고
머리 아래의 비보호 장비 셀만 바꾼다. 몸통은 머리에 직접 연결하고,
손·무기·발·탈것을 프레임 안에 완전히 넣는다. 작은 가짜 픽셀,
그라데이션, 장발, 모자/후드, 잘린 장비, 텍스트와 추가 인물을 금지한다.
배경은 단색 `#ff00ff`다.

## 클래스 장비

- 로드: 은색 지휘관 갑옷, 금색 포인트, 짧은 검, 진홍 망토
- 하이로드: 중장 은색 판금, 큰 금색 견갑, 검, 청색 방패
- 메이지: 왕청색 로브, 보라 맨틀, 금장, 청록 보석 지팡이
- 아크메이지: 백청보라 로브, 금장, 녹색 보석 지팡이
- 위저드: 남색/인디고 로브, 보라 패널, 금장, 적색 보석 지팡이
- 세인트: 백금색 성직 로브, 청색 포인트, 성직 지팡이
- 팔라딘: 백은색 판금, 금색 견갑, 검, 청색 방패
- 실버나이트: 담청은색 기병 갑옷, 남색 마갑, 진홍 포인트, 창
- 드래곤로드: 녹청색 드래곤, 진홍 날개, 은금색 기수 갑옷
- 레인저: 녹갈색 경량 갑옷, 활, 붉은 스카프
- 하이마스터: 백청색 로브/경갑, 금색 견갑, 청록 보석 지팡이

머리 일치율 90% 미만이거나 몸·무기·탈것이 잘린 후보는 폐기했다.
하이마스터는 사용자가 마지막으로 수정한 74픽셀 마스크로 다시 생성했다.
