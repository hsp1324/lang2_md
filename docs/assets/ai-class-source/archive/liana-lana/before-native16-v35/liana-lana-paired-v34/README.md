# 리아나·라나 청색·적색 짝 디자인

리아나와 라나의 겹치는 상위 클래스 11종을 같은 디자인으로 다시 만든
최신 작업물이다. 리아나의 청색 AI 원화를 마스터로 사용하고, 라나는
픽셀 위치와 실루엣을 바꾸지 않은 채 청색 장비만 적색으로 변환한다.

- `raw-blue`: OpenAI로 새로 만든 리아나 청색 AI 원화
- `raw-red`: 청색 마스터와 좌표가 같은 라나 적색 AI 원화
- `clean-blue`, `clean-red`: 보라색 생성 배경과 경계 잔상을 제거한 원화
- `logical16-blue`, `logical16-red`: 사용자 머리·얼굴 마스크를 적용한
  최종 메가드라이브용 16×16
- `liana-lana-paired-ai-and-16x16.png`: 11개 클래스 전체 비교
- `PROMPTS.md`: 생성 및 변환 조건

기본 클래스와 단독 클래스는 변경하지 않았다. 팔라딘과 실버나이트는
기병이고, 모든 클래스의 주 지팡이·검·창은 이미지 기준 오른쪽, 즉
캐릭터의 왼손에 배치했다.
