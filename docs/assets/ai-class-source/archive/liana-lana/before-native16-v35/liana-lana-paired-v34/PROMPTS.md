# 리아나·라나 짝 디자인 생성 기준

## 공통 생성 프롬프트

원작 16×16 스프라이트와 사용자가 편집한 머리·얼굴 마스크만
레퍼런스로 사용한다. 이전 AI 시안은 사용하지 않는다.

- 메가드라이브 전략 RPG용 정면에 가까운 우향 16×16 논리 픽셀 아트
- 정확한 16개 논리 행·열을 크게 확대한 균일한 사각 픽셀
- 원작의 큰 금발 머리, 얼굴 방향, 검은 눈과 왼쪽 흰자 위치 유지
- 머리는 전체 높이의 약 1/3, 몸과 장비가 분리되어 보이지 않게 연결
- 옷·갑옷·망토·탈것·무기로 모든 행과 열을 실제로 사용
- 주 지팡이·검·창은 이미지 기준 오른쪽 끝 13~15열, 캐릭터 왼손에 배치
- 단순한 16×16 판독성을 우선하고 미세 질감·안티앨리어싱·그라데이션 금지
- 평면 `#ff00ff` 크로마키 배경, 피사체에 보라·자홍색 금지
- 검은 배경·보라색 테두리·프레임·그림자·글자·UI 금지
- 리아나는 청색·백색·금색 장비를 주색으로 사용
- 라나 적색판을 동일 좌표 리컬러로 만들 수 있게 머리·피부·백색·금색은
  중립색으로 유지

팔라딘과 실버나이트에는 한 명의 기수와 한 마리의 말만 그린다.
팔라딘의 검과 실버나이트의 장창도 이미지 기준 오른쪽에 둔다.

## 클래스별 장비 지시

- `08` 힐러: 넓은 백청색 치유 로브와 수정 지팡이
- `0B` 하이로드: 백은 판금, 넓은 망토, 검
- `11` 프리스트: 백청색 제의와 성직 지팡이
- `13` 메이지: 남청색 로브와 수정 지팡이
- `14` 아크메이지: 더 풍성한 백청색 로브와 수정 지팡이
- `15` 위저드: 청백색 로브와 수정 지팡이
- `16` 하이프리스트: 백청색 고위 성직 제의와 성직 지팡이
- `18` 세이지: 청백색 로브, 마도서, 수정 지팡이
- `19` 팔라딘: 백은 판금 기수, 청색 마갑, 검
- `1D` 실버나이트: 백은 판금 기수, 청색 마갑, 장창
- `28` 서머너: 남청색 룬 로브, 두루마리, 수정 지팡이

## 16×16 변환

청색 원화에서 보라색 키와 어두운 보라색 경계 잔상을 모두 제거하고
피사체 경계를 16×16 전체에 최근접 샘플링한다. 라나는 청색 마스터와
같은 전경 알파 마스크를 사용한다. 청색 계열 장비만 메가드라이브 채널
단계의 진홍·적색으로 변환하고, 사용자 마스크의 원본 머리·얼굴·눈 픽셀은
마지막에 정확히 복원한다. 투명색을 제외한 색은 15색 이하로 제한하며,
마스크 밖의 완전 검정과 보라색 경계색은 제거한다.
