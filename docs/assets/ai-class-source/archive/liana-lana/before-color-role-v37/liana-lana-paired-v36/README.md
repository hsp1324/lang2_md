# 리아나 힐러 마스크 기반 리아나·라나 네이티브 16×16

리아나와 라나의 겹치는 상위 클래스 11종을 실제 16×16 AI 원화로 다시
만든 최신 작업물이다.

이전 작업은 1254×1254 AI 인물을 피사체 경계로 자른 뒤 16×16 정사각형에
강제로 맞췄다. 클래스마다 원화의 가로세로 비율이 달라 몸이 늘어나고,
AI 머리 위에 원본 머리를 나중에 덮어써서 머리와 몸이 분리되어 보였다.

현재 v36 작업에서는 AI 몸·장비 디자인을 다시 생성하지 않았다. 방금
사용자가 저장한 리아나 힐러의 74픽셀 마스크를 공통 좌표 기준으로 삼아
다음 순서로 다시 합성했다.

1. 리아나 힐러에서 저장한 74개 좌표를 11종 전체에 똑같이 복사한다.
2. 기존 AI 몸·장비를 피사체 크롭 없이 고정 16×16 좌표로 읽는다.
3. 각 클래스의 74개 좌표에는 그 클래스 ROM 원본 픽셀을 되돌린다.
4. 라나는 리아나와 같은 실루엣을 유지하고 장비색만 적색으로 바꾼다.
5. 에디터가 읽는 네이티브 원화와 최종 PNG를 같은 픽셀로 유지한다.

마스크 밖 몸·장비는 직전 v35와 동일하다. 단, 4bpp의 15개 가시색 제한을
맞추기 위해 라나 실버나이트의 희소한 금색 1픽셀만 가장 가까운 기존
금색으로 합쳤다. 실루엣과 장비 형태는 바뀌지 않았다.

## 폴더

- `native16-blue`: 에디터가 직접 읽는 리아나 16×16 AI 원화
- `native16-red`: 같은 좌표의 라나 16×16 AI 원화
- `preview-blue`, `preview-red`: 최근접 확대한 확인용 이미지
- `head-guides`: 힐러 마스크 74좌표에 각 클래스 원본을 표시한 가이드
- `generation-evidence`: 몸·장비 생성 과정의 원본 출력
- `liana-lana-native16-comparison.png`: 머리 가이드와 청·적 최종 비교
- `validation-report.json`: 머리 일치·실루엣·팔레트 자동 검사 결과

모든 네이티브 원화는 16개 행·열을 사용한다. 주 지팡이·검·창은 이미지
기준 오른쪽에 있고, 팔라딘과 실버나이트는 기병이다. AI 몸·장비와 기본
클래스·단독 클래스는 변경하지 않았다. 직전 v35 결과와 마스크는
`archive/liana-lana/before-healer-mask-v36`에 보관했다.
