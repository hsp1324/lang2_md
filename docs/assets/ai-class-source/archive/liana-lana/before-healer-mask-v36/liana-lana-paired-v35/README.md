# 리아나·라나 고정 머리 네이티브 16×16

리아나와 라나의 겹치는 상위 클래스 11종을 실제 16×16 AI 원화로 다시
만든 최신 작업물이다.

이전 작업은 1254×1254 AI 인물을 피사체 경계로 자른 뒤 16×16 정사각형에
강제로 맞췄다. 클래스마다 원화의 가로세로 비율이 달라 몸이 늘어나고,
AI 머리 위에 원본 머리를 나중에 덮어써서 머리와 몸이 분리되어 보였다.

현재 작업은 다음 순서를 사용한다.

1. 저장된 마스크에서 얼굴·머리·눈 픽셀만 분리한다.
2. 그 머리를 16×16 고정 캔버스의 원래 좌표에 먼저 놓는다.
3. AI에는 머리를 움직이지 않고 몸과 장비만 그리게 한다.
4. 피사체 크롭 없이 전체 캔버스의 같은 16×16 좌표를 직접 읽는다.
5. AI 원화 파일 자체에 원본 머리·눈·흰자 픽셀을 넣는다.
6. 리아나 청색판과 좌표가 같은 라나 적색판을 만든다.

## 폴더

- `native16-blue`: 에디터가 직접 읽는 리아나 16×16 AI 원화
- `native16-red`: 같은 좌표의 라나 16×16 AI 원화
- `preview-blue`, `preview-red`: 최근접 확대한 확인용 이미지
- `head-guides`: AI 입력에 사용한 원본 머리 전용 고정 가이드
- `generation-evidence`: 몸·장비 생성 과정의 원본 출력
- `liana-lana-native16-comparison.png`: 머리 가이드와 청·적 최종 비교
- `validation-report.json`: 머리 일치·실루엣·팔레트 자동 검사 결과

모든 네이티브 원화는 16개 행·열을 사용한다. 주 지팡이·검·창은 이미지
기준 오른쪽에 있고, 팔라딘과 실버나이트는 기병이다. 기본 클래스와 단독
클래스는 변경하지 않았다.
