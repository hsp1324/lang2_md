# 헤인 소서러·메이지 전폭 픽셀아트 보정

## 목표

v2에서 마지막 열을 채운 것으로 검출된 픽셀이 실제 지팡이 축이 아니라
AI의 마젠타 배경 프린지 또는 구체의 고립된 외곽 1픽셀이었던 문제를
수정한다. 얼굴·머리는 사용자 마스크와 원작 픽셀을 그대로 유지한다.

## AI 편집

OpenAI 이미지 편집 `precise-object-edit`로 v2 원화, 원작 전체 비율,
사용자 얼굴·머리 마스크를 입력했다.

- 손은 논리 x=12~13에 배치
- 보석은 x=13~15에 배치
- 갈색·금색 지팡이 축은 x=14에 배치
- 원작 먹색 외곽은 x=15에서 보석 아래부터 y=15까지 연결
- 왼쪽 로브·망토도 x=0까지 여러 행에서 사용
- 머리 크기, 얼굴, 로브 디자인과 포즈 유지
- 마젠타·보라 배경 프린지, 순수 검정, 앤티앨리어싱 금지

소서러 지팡이 구체는 보라색을 제거하고 청옥색·흰색·금색으로 바꿨다.
메이지 지팡이 수정은 녹색·흰색·금색을 유지했다.

## 배경 제거

AI가 순수 `#ff00ff` 대신 `#e407df`에 가까운 배경과 어두운 보라색
경계를 만들 수 있으므로 밝은 마젠타만 제거하지 않는다. v3 소서러와
메이지는 보라색 장비를 쓰지 않으므로 연결 여부와 관계없이 마젠타·보라
키 계열을 원화 전체에서 제거한다. 몸과 지팡이 사이에 외곽선으로
둘러싸인 배경 구멍도 캐릭터색으로 오인하지 않는다.

## 최종 16×16 직접 보정

AI 원화 축소와 얼굴 마스크 복원 뒤, 지팡이와 로브 밑단은 논리좌표로
직접 마무리한다.

- x=14: 갈색·금색 지팡이 축
- x=15: `(36,36,36)` 원작 먹색 외곽, y=3~15 연속
- y=15: 로브 밑단과 지팡이 끝을 같은 기준선에 배치
- x=0: 왼쪽 로브·망토 외곽을 최소 3행 이상 사용
- 최종 순수 검정 0픽셀
- 최종 마젠타·보라 프린지 0픽셀
- 투명색 제외 최대 15색

에디터와 비교 이미지에는 `raw/`의 크로마 배경 원본이 아니라
`clean/`의 완전 투명 배경 원화를 사용한다. AI 원화, 최종 16×16,
원작 비교는 `hein-magic-clean-ai-and-16x16.png`에 정리했다.
