# 헤인 마법 클래스 오른쪽 3열 보정

`hein-magic-native16-v1`에서 채택한 디자인을 유지하면서 소서러와
메이지의 오른손·보석·지팡이만 오른쪽 끝 3열까지 옮긴 정밀 편집이다.
아크메이지 원화는 v1 파일을 바이트 그대로 복사했으며 디자인과 변환을
변경하지 않는다.

## 공통 생성 방식

- OpenAI 이미지 편집 `precise-object-edit`
- 입력 1: v1에서 채택한 클래스별 AI 원화
- 입력 2: 해당 클래스의 원작 전체 비율 이미지
- 입력 3: 사용자가 저장한 얼굴·머리 마스크 이미지
- 순수 `#ff00ff` 배경
- 정확한 논리 16×16 격자와 균일한 사각 픽셀 블록
- 얼굴·머리·로브·색·포즈는 유지
- 오른손은 논리 x=12~13, 보석과 지팡이는 x=13~15 사용
- 지팡이 축은 보석 아래부터 발 기준선까지 연결
- 앤티앨리어싱·그라데이션·미세 픽셀·텍스트 금지

## 09 소서러

기존 청색 로브와 보라색/적색 구체 지팡이를 유지하고, 오른손과 손목을
x=12~13으로 뻗으며 구체·외곽선과 갈색/금색 지팡이 축이 x=13~15를
점유하도록 요청했다. 소매-손-지팡이와 구체-축은 각각 연결하고 잘림을
금지했다.

## 13 메이지

기존 청색 로브와 녹색 수정 지팡이를 유지하고, 오른손과 손목을
x=12~13으로 뻗으며 수정·외곽선과 갈색/금색 지팡이 축이 x=13~15를
점유하도록 요청했다. 소매-손-지팡이와 수정-축은 각각 연결하고 잘림을
금지했다.

## 후처리

두 클래스만 AI 전경의 좌우·상하 끝점을 16×16의 끝점에 최근접 대응해
가로 16칸을 활용한다. 그 뒤 메가드라이브 4bpp 팔레트로 제한하고,
사용자가 저장한 얼굴·머리 마스크 픽셀을 원작에서 완전히 복원한다.

AI 편집 원화, 마스크 적용 전 16×16, 최종 마스크 적용본, 원작은
`hein-magic-right-columns-ai-and-16x16.png`에서 한 번에 비교한다.
