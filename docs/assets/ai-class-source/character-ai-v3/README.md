# Character AI v3

이 폴더는 AI 캐릭터 에디터용 클래스 디자인 원본과 16×16 변환 비교본을
캐릭터별로 보관한다. 실제 ROM에는 자동 반영되지 않으며, 에디터 미리보기
자산만 생성한다.

새 AI 원화와 최종 16×16에서 좌우 끝 3열, 장비 연결, 머리 마스크,
메가드라이브 팔레트를 검증하는 공통 규칙은
[`../LOGICAL16-SPACE-USAGE-GUIDE.md`](../LOGICAL16-SPACE-USAGE-GUIDE.md)를
따른다.

## 생성 기준

- 이미지 생성 방식: Codex 내장 이미지 생성
- 정체성 기준: `../references/NN-original.png`의 원작 ROM 5프레임
- 스타일 기준: `../direct_16x16_01_elwin.png`
- 얼굴, 눈 위치, 머리색, 머리 길이와 앞머리 실루엣은 원작을 우선한다.
- 클래스 차이는 갑옷, 로브, 망토, 방패, 무기, 장신구와 장비색으로 표현한다.
- 기본 클래스는 원작을 그대로 두고, 하위 클래스와 맵 스프라이트가 겹치는
  상위 클래스만 새 디자인으로 바꾼다.
- 엘윈 로드는 보행 캐릭터이며 말이나 탈것을 사용하지 않는다.
- 쉐리는 모든 클래스에서 원작과 같은 턱선 길이의 단발을 유지한다.
- 아론과 레스터는 16×16 축소 뒤에도 얼굴이 작아 보이지 않도록 머리를
  몸통 대비 크게 생성한다.

사용한 공통 프롬프트 골격:

> Create a strict class-grid character sheet for a Mega Drive-era 16x16 map
> sprite conversion. Preserve the supplied original character's head identity:
> the same hair color, hair length, bangs, face scale, eye placement, and
> recognizable head silhouette in every cell. Match the compact proportions,
> palette density, dark outline, and equipment readability of the supplied
> direct Elwin style reference. Change only class equipment, armor, robes,
> weapons, ornaments, cape, and their colors. One complete character centered
> in each cell on a pure black background, with no labels, borders, detached
> props, scenery, extra characters, or cropped body parts.

캐릭터별 보정 문구와 클래스 장비 목록을 위 골격에 추가했다. 셀 순서는
`tools/build_ai_class_sprite_assets.py`의 `BOARD_SPECS`에 고정되어 있다.

2026-07-26에 다시 생성한 리아나·라나·스콧·키스·아론·레스터·제시카
`*-class-sheet-source-v2.png`는 이전 AI 시트와 엘윈 스타일 이미지를
입력으로 사용하지 않았다. 각 캐릭터의 `*-head-ratio-guides-v1` 안에
있는 원작 전체 시트와 사용자가 저장한 마스크 시트 두 장만 사용했다.
모든 시트는 마젠타 배경이며, 최종 16×16에서 사용자 마스크를 원작
픽셀로 다시 덮어쓴다. 전체 프롬프트와 셀 목록은
`remaining-commanders-v2-prompts.md`에 기록했다.

이 v2 시트와 쉐리/헤인 전용 구판은 현재 적용본에서는 교체되었다.
현재 엘윈 이외 9명은 `../logical16-v3`의 새 4×4 시트를 사용한다.
각 시트는 해당 캐릭터의 원작 보드와 현재 사용자 마스크 보드만 이미지
입력으로 사용했으며, AI 단계부터 실제 16×16처럼 16칸 이하의 큰 사각
픽셀로 단순하게 생성했다. 빌더는 셀 경계를 넘은 로브·지팡이·탈것도
연결된 한 캐릭터로 먼저 복원해 이웃 셀 조각을 제거하고, 전체 실루엣을
최근접 방식으로 16×16에 맞춘다. 15개 가시색 중 원작 머리색을 먼저
예약하고 남은 색에는 메가드라이브 채널값으로 보정한 AI 장비색을
배치하므로 위저드의 보라 망토 같은 클래스 고유색도 유지된다. 마지막에
저장 마스크를 원작 픽셀로 적용한다. 생성 지시와 클래스 순서는
`../logical16-v3/PROMPTS.md`에 기록했다.

엘윈의 현재 적용 원화는 `../elwin-native16-v16`이다. 소드마스터는
원작·마스크를 정체성 기준으로, 사용자가 지정한 하이로드를 장비 스타일
기준으로 사용해 양쪽에 금색 견갑을 추가했다. 쌍검·양손과 경량 몸
비율은 유지했다. 히어로는
원작 전체 스프라이트와 사용자 마스크만으로 다시 생성해 잘리지 않은
양손과 왼손에 연결된 완전한 칼을 갖춘 중장 실루엣으로 교체했다.
소드마스터도 v12에서 원작과 마스크만 사용해 양손에 한 자루씩 연결된
쌍검 실루엣으로 교체했다. 메이지,
하이랜더, 나이트마스터는 해당 클래스의 원작 전체 스프라이트와 사용자
마스크 두 장만으로 보수적으로 다시 생성했다. 이전 AI 출력은 히어로,
메이지, 하이랜더, 나이트마스터의 이미지 입력으로 사용하지 않았다.
v16에 포함된 소드마스터는 사용자가 하이로드처럼 만들라고 지정했으므로 하이로드
이미지를 견갑 스타일 기준으로만 추가 사용했다. 원작의 자세, 몸·말
실루엣, 장비 배치,
주요 색 계열을 약 80% 유지하고 클래스업 장식만 소폭 추가했다. 나머지
5개 클래스는 v9 채택본을 유지했다. 마스크의
`y=0~8` 경계는 머리 높이가 아니라 무기와
투명 픽셀까지 포함한 보존 영역이다. 따라서 v16은
`../elwin-head-ratio-guides-v2/*-original-full-ratio.png`의 원작 전체
16×16을 신체 비율 기준으로 사용하고, `*-masked-identity.png`는
정체성 픽셀 기준으로만 사용한다.

v16은 원출력 머리가 사용자 마스크와 90% 이상 일치하고 머리에 연결된
몸·장비가 45논리픽셀 이상인 조건에 더해, 머리와 몸이 같은 굵은
논리픽셀 크기를 사용하고 목·어깨가 직접 연결된 결과만 채택했다.
채택본은 마스크 좌표를 원작 값으로 100% 고정한 `logical16` 원화를
사용한다. 갑옷·로브·말·장비는 큰 색 덩어리로 단순화하고, 전체 전신은
16×16 안에 유지했다.
로드·하이로드·비숍·메이지·아크메이지·소드마스터·히어로는 보행이며,
하이랜더·나이트마스터·실버나이트만 기병이다.

배경은 제거 가능한 단색 `#ff00ff`다. 생성 모델의 얼굴 좌표는
근사치이므로 최종 16×16에서는 사용자 마스크의 59~73픽셀을 원작 값으로
다시 기록해 완전 일치를 보장한다.

## 파일

- `*-class-sheet-source-v2.png`: 원작 전체 비율과 사용자 마스크만
  입력으로 다시 생성한 클래스별 원본 시트
- `elwin-mage-archmage-source-v3.png`: 이전 메이지/아크메이지 원본 기록
- `../elwin-native16-v16/*.png`: 현재 적용하는 엘윈 상위 클래스 10개
  원화. 히어로·소드마스터·메이지·하이랜더·나이트마스터는
  원본·마스크를 정체성 기준으로 새로 생성했고, 소드마스터는 하이로드
  견갑을 장비 스타일로 추가 참조했다. 나머지 5개는 v9 채택본을 유지했다.
  소드마스터는 사용자가 다시 저장한 83픽셀 마스크의 양쪽 넓은 견갑
  좌표까지 원작 픽셀로 채운다.
  아크메이지는 v16에서 메이지보다 넓은 청금색 어깨 맨틀, 겹친
  백청색 로브와 큰 청색 보석 지팡이를 사용하도록 다시 생성했다.
  저장된 69픽셀 머리 마스크는 AI 원화와 최종 16×16 양쪽에서 모두
  원작과 완전히 일치한다.
- `../elwin-head-ratio-guides-v2/*.png`: 원작 전체 비율 및 사용자 마스크
  정체성 픽셀 가이드
- `../sherry-native16-v1/*.png`: 이전 AI 시트 없이 클래스별 원작과
  사용자 마스크로 생성한 쉐리 상위 중복 클래스 11개. 모든 클래스에서
  턱선 길이 은발 단발과 큰 머리를 유지한다.
- `../latest/hein`: 현재 적용하는 헤인 상위 중복 클래스 11개의 신규
  AI 원화, 정리된 원화, 최종 16×16 및 비교판. 이전 AI 작업물은
  참조하지 않고 클래스별 원본과 사용자 마스크만 사용했으며, 최종
  디자인은 16개 행과 열을 모두 사용한다.
- `../archive/hein`: 현재 적용하지 않는 이전 헤인 v1-v3 작업 기록.
- `../logical16-v3/*/*-logical16-sheet-ai.png`: 현재 적용되는 엘윈 외
  9명의 원작·마스크 기반 논리 16×16 AI 클래스 시트
- `*-ai-and-16x16.png`: AI 원본, 최종 16×16, 원작 ROM을 한 장에서 비교한 시트

최종 16×16은 AI 원본의 전경과 새 장비·말 실루엣을 비율 유지한 채
축소하고, 해당 캐릭터의 원작 ROM 팔레트로 매핑한 다음 얼굴 마스크
픽셀을 원작에서 복원한다. 마스크는 AI 캐릭터 에디터에서 픽셀 단위로
수정할 수 있다.
