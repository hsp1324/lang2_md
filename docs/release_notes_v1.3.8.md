# v1.3.8 릴리스 노트

## 변경 내용

- 최신 디자인 일반판(Normal)과 하드판(Hard)의 **로렌 하이로드 맵 외형**에서
  기존 연보라 두 단계 명암을 **밝은 빨강 → 짙은 빨강** 그라데이션으로
  교체했습니다.
- 원작 디자인판(Original)은 원작 외형을 유지하므로 이 색상 변경 대상이
  아닙니다.
- 방패·장식·검의 보호 색상과 클래스·능력치·경험치·대사·시나리오 데이터는
  이 변경으로 수정하지 않았습니다.
- 에디터의 로렌 대표 미리보기도 같은 빨강 명암과 따뜻한 하이라이트로
  갱신했습니다.

## 호환성

게임 내 SRAM 저장 형식은 계속 `lang2-ko-sram-v1`입니다. 다른 ROM 해시의
에뮬레이터 상태 저장(`.state`, `.gst`)은 불러오지 않는 것을 권장합니다.

배포 전 확인 범위와 정확한 BPS/ROM 검증값은
[v1.3.8 검증 기록](v1.3.8_validation.md)을 따릅니다.
