# v1.4.2 릴리스 노트

## 시나리오 26에서 비밀 시나리오 X4 정상 진입

Normal·Hard에서 시나리오 26을 처음 정상 클리어할 때 에그베르트의
`죽음의 탑` 도전 제안이 나올 수 있도록 진입 판정을 수정했습니다.

원작 판정은 이 이벤트가 끝난 뒤에 기록되는 시나리오 26 클리어 기록을
이벤트 도중 미리 요구하고 있어, 조건을 지킨 첫 정상 진행에서는 통과할 수
없었습니다. v1.4.2는 다음 조건을 그대로 유지하면서 이미 시나리오 26을 한 번
클리어했어야 한다는 선행 조건만 제거합니다.

- 시나리오 1~25 완료
- 비밀 시나리오 X1~X3 완료
- 현재 배치된 아군 지휘관 생존
- 영구 아군 지휘관 10명의 누적 퇴각 0회

제안 대사, 수락·거절 분기와 목적지 X4는 원작 그대로입니다. Original은
번역만 적용하는 판의 원칙에 따라 원작 진입 판정을 유지합니다.

## 호환성

SRAM 형식은 v1.4.1과 같습니다. 업데이트할 때는 상태 저장 대신 게임 안에서
저장한 `.srm`을 사용하세요.
