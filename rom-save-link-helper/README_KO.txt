랑그릿사 II ROM 업데이트 · 저장 연결 도우미 1.0.0

Android
1. ZIP을 풀고 index.html을 브라우저로 엽니다.
2. 현재 플레이 ROM과 최신 ROM을 선택합니다.
3. 기본값인 "기존 ROM 이름 유지"에서 연결 ROM을 저장합니다.
4. 기존 ROM을 백업하고, 내려받은 ROM으로 교체합니다.
5. RetroArch의 기존 .srm/.sav는 그대로 둡니다.

Windows
- open_windows.bat을 실행합니다.

Ubuntu
- open_linux.sh를 실행하거나 index.html을 브라우저로 엽니다.

새 ROM 이름을 유지하려면 저장 파일 또는 RetroArch 저장 폴더를 함께
선택하고 "최신 ROM 이름 사용"을 고릅니다. ROM과 이름이 맞춰진 저장
파일을 각각 저장한 뒤 기존 위치에 배치합니다.

에뮬레이터 상태 저장(.state)은 호환을 보장하지 않습니다. 업데이트
전에 반드시 게임 메뉴에서 저장하고 RetroArch를 완전히 종료하세요.
