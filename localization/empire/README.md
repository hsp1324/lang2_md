# 제국편 V2.0(96%) 한글화

이 디렉터리는 오리지널·하드판과 완전히 분리된 제국편 전용
한글화 자료다. 입력 ROM은 SHA-256
`7004ad55f28340144f3248d7386d4bbc76a076491899af5e872f5854802be179`인
`Langrisser2帝国篇V2.0(96%).BIN`만 지원한다.

- 제국편의 전직 트리, 능력치, 용병, 맵, 적 구성과 이벤트 조건은
  변경하지 않는다.
- 공통 메뉴·아이템·마법 용어는 기존 한글판의 검수된 표기를
  재사용한다.
- 제국편에서 순서가 바뀐 캐릭터·직업 ID는 ROM 원문 테이블로 다시
  식별한다. 오리지널판의 ID 표를 그대로 사용하지 않는다.
- 제국편 고유 시나리오 1~27과 부가 시나리오의 대사는 별도 원문에서
  추출·번역·삽입한다.
- 기계 번역 산출물 `draft/`는 초벌 자료이며 검수본으로 취급하지
  않는다.

## 현재 진행 상태

- 이벤트 대사 3,214개, 승패 조건 32개, 시나리오 설명 31개를 전용 영역에
  손실 없이 재배치하는 빌더와 밸런스 데이터 변경 방지 검사가 있다.
- 대사처럼 보이는 시나리오 메타데이터 2개는 원문 지문과 전체 워드열을
  검증해 번역·재배치 대상에서 제외한다. 내부 이벤트 포인터만 새 대사
  위치로 갱신하고 나머지 데이터는 그대로 보존한다.
- 캐릭터·클래스 이름, 기본 메뉴, 전투 명령과 유닛 안내, 지휘관 배치
  경고, 상점·아이템 이름/설명, 타이틀·불러오기, 마법 목록 및
  오프닝/엔딩 고정 문구는 제국편 고유 주소를 검증한 뒤 한글화한다.
- 중국어판에서 0x10바이트 앞당겨진 상점/아이템 표는 원본판 주소와
  분리했다. 이 경계를 회귀 테스트와 소스 영역 변경 해시로 고정한다.
- 아직 사람 검수가 끝나지 않은 대사가 있으므로 현재 빌드는 진단용이며
  배포판으로 표시하지 않는다. 정확한 잔여 수는 `reviewed/audit.json`에
  기록한다.

캐릭터와 전직/고용 자료는 사용자가 제공한 네이버 블로그 두 글과
ROM 실데이터를 교차 확인한다. 블로그 표기와 ROM 데이터가 다르면
게임 동작을 보존하기 위해 ROM 데이터를 우선하고 차이를 기록한다.
교차 검증 결과와 표기 원칙은 [references.md](references.md)에 정리한다.
